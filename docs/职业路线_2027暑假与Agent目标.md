## 5. 长期旗帜项目：对标 pi 的自研 agent

- pi（earendil-works/pi）实测：TS monorepo、11 包、~28 万行 → **对标=功能面逼近的个人版，不是复制其工程规模**。
- 7 模块地图：① 多厂商 LLM 抽象 ② Agent 运行时（tool-calling 循环）③ 工具+权限沙箱 ④ 会话存储 ⑤ CLI/TUI/Web 界面 ⑥ 工程化 ⑦ 分发。地基主要由后端课程覆盖（OS/DB/网络/工程），AI 部分自学。
- 分代里程碑：v0（2027-04，~200 行 CLI 对话）→ v1（+工具+tool 循环，500–1000 行）→ **v2（2027 暑假，多工具+SQLite 会话=完整 agent 雏形）** → v3（大二，provider 抽象+沙箱+Web）。
- 反噬疫苗：① 对标是远景，近期任务永远是 v0 ② agent 不许吃掉后端主线（OSPP/实习/秋招优先）③ agent 用 **Python**（生态最强 + 零新增语言成本），与后端主线解耦——不被 pi 的 TS 绑架，也不被"同一门语言"绑架。
- 参考合法：pi 为 MIT，读/借架构/提 PR 均可；对标=自己的实现。

### 8.1 为什么方向可能翻转
旧结论（Java 主线）最强论据是"银行/国企/全国盘兜底"——被新约束删除；同时深圳是 Go 密度最高的城市之一（腾讯新业务/字节深圳/Shopee/富途/货拉拉），Go 的"岗位集中"缺点在深圳被削弱。两项同向 → 矩阵总分翻转为 Go 领先（≈7.5 vs ≈6.6，权重见对话记录）。

### 8.2 草案方案包
**主线 = Go｜旗帜 agent = Python｜第二语言 = Java（大二上补，双投通道）**
- 深圳雇主地图：Go → 腾讯（新后台）/字节深圳/Shopee/富途/货拉拉；Java → 华为部分/平安系/微众/全国泛 Java 盘。
- 时间线微调：寒假 Go 核心 + Web 项目1（Gin+MySQL）；大一下 Go 深化+上线 + Mini-Agent v0（Python）；OSPP 优先 Go/云原生系；大二上补 Java → 2028 实习 Go/Java 双投。
- 不变项：agent 分代路线、蓝桥杯 Python 组、CET-4、绩点底线、军训 Python 主线。

### 8.3 DIY 验证作业（12 月定案前必做，30 分钟）
统计五类深圳 JD 的语言字眼与岗位数：① 腾讯后台开发-深圳 ② 字节深圳后端 ③ Shopee 深圳后端 ④ 华为通用软开-深圳 ⑤ 平安/微众后端。拿到数据回来**按真实权重重算 §8 矩阵**；若结果与草案相反（Java 领先），以数据为准改判。

### 8.4 防内耗纪律
语言决策只占求职权重的 ~20%；12 月中必须定案；定案后 80% 精力给项目/刷题/实习节奏。若 2028 前市场信号变化（如 Go 岗收缩），用数据复检再改——旧结论可被新证据推翻。
