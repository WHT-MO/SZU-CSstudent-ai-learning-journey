# L03 · 循环 while / for / range（让程序学会重复干活）

> 本课目标：学完能写九九乘法表 + 猜数字游戏。
> 验收：九九乘法表（自写）+ 猜数字（带计数）+ 洛谷 P5722 数列求和 AC。
> 顺序 → 分支 → 循环 = 编程三大件，本课集齐。

## 1. 为什么要循环

程序要"重复干同一件事"：打印 14 行、求和 1..100、猜数字猜到你中为止。
两种场景 → 两兄弟：

| | while | for + range |
|---|---|---|
| 适合 | **不知道几次**，看条件停 | **知道几次**，数着来 |
| 生活类比 | 站军姿"直到教官喊停" | "把 14 天军训各报数一遍" |

## 2. while：条件为真就一直做

```python
i = 3
while i > 0:        # 条件 True 就重复
    print(i)
    i = i - 1       # ⚠️ 计数器！忘了它 = 死循环
print("发射！")
```

**死循环 = 条件永远 True 且没有任何东西让它变 False** → 程序永远跑不完（Ctrl+C 强制中断）。

## 3. for + range：数着来

```python
for n in range(1, 6):    # 1,2,3,4,5
    print(n)
```

- `range(5)` → 0,1,2,3,4（从 0 开始）
- `range(1, 6)` → 1..5（**前闭后开**：含起点 1，不含终点 6！）
- `range(1, 10, 2)` → 1,3,5,7,9（第三个是步长）

⚠️ 最易错点：`range(1, 10)` **不含 10**。想 1..10 必须写 `range(1, 11)`。

## 4. break / continue：循环里的刹车和跳步

- `break`：**立刻退出整个循环**（遇到就撤，后面的都不跑）
- `continue`：**跳过本次剩下的**，直接进入下一次

```python
for day in range(1, 15):
    if day == 8:
        print("休整一天，跳过")
        continue          # 8 不打印"第X天"，跳到 9
    if day == 13:
        print("提前收操")
        break             # 循环到此结束
    print(f"军训第{day}天")
```

## 5. 累加器模式（OJ 求和题专用）

```python
total = 0                      # 先清零
for day in range(1, 15):       # 1..14
    h = int(input(f"第{day}天训练几小时？"))
    total = total + h          # 累加
print(f"14天共{total}小时")
```

## 6. 嵌套循环：循环套循环（九九乘法表的钥匙）

外层走一步，内层走完一整圈：

```python
for i in range(1, 4):
    for j in range(1, 4):
        print(i, j, end=" | ")   # end= 结尾用竖线代替换行
    print()                      # 内层一圈结束 → 换行
```

## ⚠️ 本课最易错 5 条

1. 死循环：while 忘改条件 / 忘计数器
2. `range(1, 10)` 不含 10（前闭后开）
3. `=` 与 `==` 又混了
4. 循环体忘缩进（老熟人了）
5. break（撤出整个循环）和 continue（只跳本次）分不清
