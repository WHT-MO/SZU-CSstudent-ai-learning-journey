## 1. 心智模型：内存是"桌面"，文件是"抽屉"

- 之前程序里所有变量都活在**内存**里——程序一关，桌面一清，什么就都没了（L08 的打卡数据就是这样丢的）。
- **文件 = 硬盘上的抽屉**：写完关掉电脑也在。文件读写就是在"桌面"和"抽屉"之间搬东西。
- 通识织入（本课配套）：程序跑在**内存**里、数据存在**硬盘**上；`路径` 就是"抽屉的门牌号"。

## 2. `with open(...) as f` —— 开门干活，出门自动关门

```python
with open("打卡状态.txt", "r", encoding="utf-8") as f:   # 开门，把门把手交给 f
    last, d = map(int, (f.read().split()))               # f.read() 把整个文件读成一串文字
```

三个位置参数各管一件事：

| 位置 | 是什么 | 说明 |
|---|---|---|
| `"打卡状态.txt"` | **路径** | 要开哪个文件 |
| `"r"` | **模式** | 开门干什么（见 §3） |
| `encoding="utf-8"` | **编码** | 用哪本"字典"把字节翻成字（见 §5） |

- `with` 的好处：**用完自动关门**（不用手写 `f.close()`，中途报错也会关）。
- `f.write()` 写、`f.read()` 整串读回。
- ⚠️ **`\n` 必须自己写**：`write` **不会**自动换行（想换行就在字符串末尾自己加 `\n`）。

## 3. 模式三兄弟 `"r"` / `"w"` / `"a"`

| 模式 | 意思 |
|---|---|
| `"r"` | 读。**文件不存在就报错**（`FileNotFoundError`） |
| `"w"` | 写。**先把文件清零**再写（原内容全没了） |
| `"a"` | 追加（append）。在**末尾接着写**，不清零 |

**判据一句话**：**状态快照用 `"w"`，日志才用 `"a"`。**
打卡存档存的是"**当前状态**"（上次打卡第几天、连续多少天），每次重写一遍才对；只有"要留历史记录"的场合才用追加。

> 卡点：当天真撞过——**两次 `"w"` 各写一行，只剩后写的**。因为第二次 `"w"` 一开门就把文件清零了。

## 4. 异常处理：`try / except` 只抓你预期的错误

```python
try:                                                      # 试着干这件事
    with open("打卡状态.txt","r",encoding="utf-8") as f:
        ...
except FileNotFoundError:                             # 只有"文件不存在"这一种情况，走这里
    print("还没有存档，这是第一次运行")
```

- **只抓具体的类型**：这里只抓 `FileNotFoundError`。
- **不写裸 `except`**：裸 `except:` 会把**你自己的 bug 也一起吞掉**（程序不报错，但你永远找不到错在哪）。
- **报错的最后一行就是类型名**：`FileNotFoundError`（文件没找到）、`ValueError`（值不对，比如空文件拆不出两个数）。以后看到红色报错，先读最后一行。

## 5. 编码：字 ↔ 字节的"对照字典"

- **编码 = 字和字节之间的对照字典**。同一个字，不同字典对应的字节不同。
- **乱码 = 写和读用了不同的字典**——文件本身**没坏**，只是拿错了字典去翻。
- 中文 Windows 的默认编码是 **GBK**，所以读写**两端都要显式写 `encoding="utf-8"`**。
- 如果文件被 BOM 污染（开头多几个看不见的字节），读的时候用 `"utf-8-sig"`。
- 顺带一个反直觉结论：**纯数字 / 纯英文在两本字典里的字节是一样的**，所以"只有中文才乱码"。

## 6. 路径：相对路径跟的是 cwd

- **相对路径相对的是 cwd = "敲命令时你所在的目录"**，不是脚本文件所在的目录。
- 所以**换个目录跑，存档就落在那个目录里**（找不到存档 = 很可能是在别的目录跑的）。
- 本程序的用法因此写成先 `cd` 再跑（见 `code\L10\kaoqin.py` 文件头第 35–37 行）：

## ⚠️ 当天真撞过的坑（含原始报错）

1. **`"w"` 会先把文件清零**：两次 `"w"` 各写一行 → 只剩后写的。要接着写用 `"a"`。
2. **相对路径跟 cwd，不跟脚本位置**：换个目录跑，存档落在那个目录。
3. **编码两端要一致**：`gbk` 的字节按 `utf-8` 读就是乱码；读写都要显式 `encoding="utf-8"`。

容器是怎么一路换过来的（学员自产思路）：
