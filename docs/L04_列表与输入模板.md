## 1. 为什么需要列表

存 14 天训练小时：`h1, h2, ..., h14` 是 14 个变量？蠢死了。
**列表 = 一个盒子装一串数据，每个数据有编号（下标）。**

```python
scores = [85, 92, 78, 90]
print(scores)      # [85, 92, 78, 90]
print(scores[0])   # 85    ← 第 0 个！
print(scores[3])   # 90    第 3 个 = 第 4 位同学
print(scores[-1])  # 90    倒数第 1 个
print(len(scores)) # 4     长度
```

⚠️ **下标从 0 开始**：第 1 个元素在 `[0]`，最后一个在 `[len-1]`。

## 2. 常用操作

```python
nums = []          # 空列表
nums.append(10)    # 尾部追加 → [10]
nums.append(20)    # → [10, 20]
nums[0] = 99       # 修改第 0 个 → [99, 20]

for n in nums:     # 遍历：一个个拿出来
    print(n)

scores2 = [85, 92, 78, 90]
print(scores2[1:3])  # 切片 [92, 78]（含头不含尾，又是前闭后开！）
```

## 3. 破译咒语：input().split() + map

洛谷最常见的输入："一行多个数字，空格隔开"。拆解咒语：

```python
line = input()          # ① 拿到一整行字符串，如 "3 5 7"
parts = line.split()    # ② split() 按空格切碎 → ['3', '5', '7']（还是文本！）
a = int(parts[0])       # ③ 逐个 int 转数字
b = int(parts[1])
c = int(parts[2])
```

合体咒语（等价）：

```python
a, b, c = map(int, input().split())
```

- `input()` 给一整行 → `.split()` 切成小段 → `map(int, ...)` 把每一段都变数字 → 分别装进 a、b、c
- 个数很多、要存起来时：`nums = list(map(int, input().split()))`
- `split()` 默认按**任意空白**切（空格/Tab/换行都算）

⚠️ 常见翻车：忘了 `int()` → 字符串相加是拼接（"3"+"5"="35"）；忘 `.split()` → `int("3 5")` 直接 ValueError。

## 4. 跟着敲（两个程序）

```python
# ① 咒语实战（P1001 A+B 就是它）
a, b = map(int, input().split())
print(a + b)
```

```python
# ② 一堆数的和与平均
nums = list(map(int, input().split()))   # 输入：10 20 30 40 50
total = 0
for n in nums:
    total = total + n
print("总和", total)            # 150
print("个数", len(nums))        # 5
print("平均", total / len(nums))  # 30.0
print("最大最小", max(nums), min(nums))  # 内置函数
```

## 5. 心智模型：变量 vs 列表

- **变量** = 单个盒子（装一个值）
- **列表** = 一排编了号的储物柜（0 号柜、1 号柜…）
- **for 遍历** = 从 0 号柜走到最后一号柜，逐个查看

## ⚠️ 本课最易错 4 条

1. 下标从 0 开始（第 5 个元素是 `[4]`）
2. 忘 `.split()` → `int("3 5")` 报错；忘 `int()` → 变拼接
3. 越界：`IndexError: list index out of range`（柜子编号超了）
4. 需要"序号"才用 `range(len(nums))`；只要元素就直接 `for x in nums`
