## 1. 运算符家族

**算术**：`+ - * / // % **`
- `/` 真除法：`7/2 = 3.5`；`//` 整除取商：`7//2 = 3`；`%` 取余数：`7%2 = 1`
- `**` 幂：`2**3 = 8`
- `%` 用途：判断奇偶、闰年、循环里取模——今晚就用它

**比较**：`==`(等于！) `!=`(不等于) `> < >= <=` → 结果永远是 **True / False**（布尔值）

**逻辑**：`and`(并且) `or`(或者) `not`(取反) → 用来组合多个条件

优先级记忆：**算术 > 比较 > and/or**（`and` 优先于 `or`）；拿不准就加括号，括号最稳。

## 2. 布尔值：程序的"是/不是"

比较表达式就像向程序提问，答案只有两种。`True`/`False` 是 `bool` 类型。
程序做决定 = 不断问"是/不是"的问题。

## 3. if / elif / else 语法

```python
if 条件:            # ① if 行末尾必须有冒号
    事情1           # ② 缩进（4 空格）表示"这条路上的事"
    事情2
elif 条件2:         # 否则再看下一个条件
    ...
else:               # 以上全不满足就我上
    ...
```

三条铁律：
1. `if` 行末**冒号**不能少（忘了 = SyntaxError）
2. **缩进**决定代码块——同一分支的事缩进必须一致（错了 = IndentationError）
3. **从上往下**，第一个成立的条件生效，后面的 elif/else 都不再检查

## 4. 跟着敲（两个可运行示例）

```python
# ① 成绩等级判断器（elif 链）
score = int(input("输入成绩(0-100): "))
if score >= 90:
    print("A")
elif score >= 80:
    print("B")
elif score >= 70:
    print("C")
elif score >= 60:
    print("D")
else:
    print("不及格")
```

## 5. 闰年规则（今晚目标题的数学）

> 四年一闰，百年不闰，四百年再闰

```python
year = int(input())
if (year % 4 == 0 and year % 100 != 0) or (year % 400 == 0):
    print(1)      # 闰年
else:
    print(0)      # 平年
```

自测：1900→0（能被100整除但非400倍数，平年），2000→1，2024→1，2026→0。
