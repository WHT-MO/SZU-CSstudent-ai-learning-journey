## 1. 输入三件套（已学 A–D 为正区；E 见 §10 预览）

```python
# A. 单个数/一行文本
n = int(input())              # input 给文本，要当数字必须 int()

# B. 一行多个数 → 拆开用
a, b = map(int, input().split())

# C. 一行多个数 → 存起来用
nums = list(map(int, input().split()))

# D. 多行：先给 n 再给 n 行
n = int(input())
for _ in range(n):            # _ = "这个循环变量我不关心"
    line = input()
```
**铁律**：`input()` 给一整条 → 要么当文本处理，要么先 `split()` 再 `map`，绝不直接对整串 `map(int, ...)`。

## 2. 容器四件套（全部已学）

```python
lst = [1, 2, 3]          # list  排队名单：有序可改
tup = (1, 2, 3)          # tuple 封条盒：有序不可改
st  = {1, 2, 3}          # set   磁贴盒：无序唯一
dct = {"a": 1}           # dict  点名册：键→值
# 空容器：[] 空 list｜set() 空 set ｜{} 空 dict（不是空 set！）
single = (1,)            # 单元素 tuple 必须加逗号
lst[0]; tup[-1]          # 下标取（有序的都能下标）
x in st                  # "在不在"：set/list 可；dict 查的是键
for k, v in dct.items(): # 键值一起遍历（已学）
```
> **为什么 `for k in dct` 拿到的是键**（09-11 讲透）：字典的"身份"就是键——像通讯录先看名字列表。所以"逐个"默认给键，**没有第二种默认**。
> **`items()` 只解决一件事**：把每一对打包成 `(键, 值)` 交出来。`for k, v in ...` 的两个变量就是**拆包**（和 `a, b = (1, 2)` 同族）；只写 `for k in dct.items():` 拿到的是整个配对。
> **`items` 后面的 `()` 是"执行扳机"**；`d.` 是告诉它"打包哪个字典"。（对比：字符串/列表没有 `items`，写了会 AttributeError。）

## 4. 字符串清洗套路（方法均为 L05 已学列表内）

```python
s = input().strip().lower()      # 去首尾空白 → 变小写（链式）
words = s.split()                # 切词 → len(words) = 词数
joined = "-".join(words)         # 反着粘回（split 的兄弟）
cnt = line.count(" ")            # 数空格
"123".isdigit()                  # 纯数字文本判断
s = s.upper()                    # upper/lower 返回新串，必须接住
line.rstrip()                    # 去【行尾】空白（09-11 转正：P1598 打印行用它清尾）
```
> **`()` 是什么**：括号 = "**执行这个动作**"（扳机）；空括号也是必须写的——`f` 只是名字，`f()` 才执行。
> 括号里放**参数**：`split()` 空着=按空白切、`split(",")`=按逗号切；`rstrip()` 空着=去所有行尾空白、`rstrip("。")`=只去句号。

## 5. 累加器 · 取最值 · 两位小数（09-11 起，09-14 补后两项）

```python
total = 0
for x in nums:
    total = total + x        # ① 最啰嗦、最清楚（先学这个）
    total += x               # ② 同义简写：+= 就是"自己加自己"；减一写 -=（h -= 1）
print(sum(nums))             # ③ 求和专用捷径：sum(一堆数) → 一个数（09-11 解锁）
```
> - `sum` **只做求和**：累乘（阶乘）、拼字符串、边算边判断，仍然要手写循环 + `+=`。
> - `sum` 的前提是那堆东西**已经是数字**（所以常写成 `sum(list(map(int, input().split())))`）。
> - `total += (x <= l)` 这种"条件当 1/0 用"的压行技巧**存在但不推荐**：牺牲可读性，你知道有这条路即可。

```python
max(nums); min(nums)         # 最大 / 最小（09-14 转正）：直接给一个值，不用自己写循环比
                             # ⚠️ 空容器 → ValueError（学员 09-14 实跑：max([]) 报错）
print(f"{avg:.2f}")          # 保留 2 位小数（09-14 转正）：`:` 后面是【格式说明符】
                             #   `.2` = 小数点后 2 位；`f` = 定点小数 → 位数不足【补 0】
                             # ⚠️ round(x, 2) 不能替代：round(2.0, 2) 打印出来还是 2.0
```

## 7. 函数 def（L07 已学）

```python
def average(a, b, c):        # def = 造工具（只造不跑）；a b c 是参数（形参）
    total = a + b + c        # 函数体：缩进的这几行，每次调用整段跑一遍
    return total / 3         # 交货：把结果【递出去】（能接住、能再算）
print(average(90, 80, 100))  # 调用：写 名字(...) 才真的执行

def f1(a, b):
    print(a + b)             # 只"喊给人听"，没有 return
r = f1(1, 2)                 # → r 是 None（没 return 的函数自动交 None）
```
> - **`print` / `.append` 都"只做事不交货"**（调用处拿到 `None`）；`return` 才是交货。
> - **返回多个值**：`return x, y` → **打包成元组**；调用处 `w, d = week(5)` → **拆包接住**（同 `a, b = (1, 2)`）。
> - **`return` 交出去的值必须有人用 `=` 接住**，否则等于丢弃。
> - **作用域**：函数体里造的变量出了函数就没了（"临时工"）；**函数内给参数赋值只改副本，外面不变** → 想影响外面，只能 `return` 再在外面接住。
> - 小技巧：`print(a, *week(b))` 的 `*` = **把容器就地摊开**（能用，但显式接住更好读）。

## 8. 易混对照表（全部基于已学内容，写完自查）

| 混淆点 | 正确 | 错误/坑 |
|---|---|---|
| 赋值 vs 相等 | `==` | `=` |
| input 类型 | `int(input())` | `'18'+1` 炸 |
| 大小写转换 | `s = s.upper()` | 不接住 = 白干 |
| range 终点 | `range(1, n+1)` | `range(1, n)` 少了 n |
| 空集合 | `set()` | `{}`（是空 dict） |
| 单元素元组 | `(1,)` | `(1)` |
| 字典取值 | `dct.get(k, 默认)` | `dct[缺的k]` → KeyError |
| 拆字符 vs 拆词 | 先 `.split()` | 忘 split 直接处理整串 |
| 引号 | 英文半角 `"` `'` | 全角引号 → SyntaxError |
| 下标起点 | 第 1 个是 `[0]` | 从 1 数 → 错位 |
| dict[键] 的读写 | `=` 左边=写 | = 右边才=读（刚锁的关键） |
| range 三参 step | 终点只要 > 最后一个目标值即可（`range(3,13,3)` 与 `range(3,15,3)` 同结果） | `range(3,12,3)` 会**吃掉** 12；`range(3,3,3)` → 空 `[]` |
| while 推进 | 循环体里必须有 `h -= 1` 之类让条件终会变假的动作 | 条件恒真 → **死循环**刷屏（09-11 实撞） |
| map 逐个对象 | `map(int, x)` 对 x 的**每个元素**处理 | 直接喂整行文字 → **逐个字符**（`"12"` 变成 1 和 2）；必须先 `.split()` |
| 空容器取最值 | 先确认里面有数 | `max([])` → `ValueError: max() iterable argument is empty`（09-14 学员实跑） |
| 保留两位小数 | `f"{x:.2f}"`（管【显示】，位数不足补 0） | `round(x, 2)` 只管数值 → `round(2.0, 2)` 打印仍是 `2.0`（P5726：第 3 次格式类错） |
| 遍历字典 | `for k in d` → **键**（字典的身份就是键） | 以为拿到值；要键值一起用 `for k, v in d.items()` |
