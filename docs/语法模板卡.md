## 1. 输入三件套（最高频，OJ 与一切程序的地基）

```python
# A. 单个数/一行文本
n = int(input())              # 为什么：input 给文本，要当数字必须 int() 翻译

# B. 一行多个数 → 拆开用
a, b = map(int, input().split())   # split 切块 → map 逐个变 int → 解包

# C. 一行多个数 → 存起来用
nums = list(map(int, input().split()))   # 为什么 list()：要下标/遍历/排序

# D. 多行：先给 n 再给 n 行（洛谷最常见）
n = int(input())
for _ in range(n):              # _ = "这个循环变量我不关心"
    line = input()              # 每轮读一行，处理它

# E. 多行：不知道几行 → 读到 EOF（没输入为止）
import sys                      # 为什么：input 读到没输入会报错，sys.stdin 不会
for line in sys.stdin:
    s = line.rstrip("\n")       # 为什么：读进来的行自带换行符，去掉再处理
```
**铁律**：`input()` 给的是一整条 → 要么当文本处理，要么先 `split()` 再 `map`，**绝不直接对整串 map(int, ...)**。

## 2. 容器四件套：造一个 / 怎么用

```python
lst = [1, 2, 3]          # list  排队名单：有序可改
tup = (1, 2, 3)          # tuple 封条盒：有序不可改（打包/防误改）
st  = {1, 2, 3}          # set   磁贴盒：无序唯一（去重/查在不在）
dct = {"a": 1}           # dict  点名册：键→值
# 空容器：[] 空 list｜() 空 tuple｜set() 空 set ｜{} 空 dict（不是 set！）
single = (1,)            # 为什么逗号：否则 (1) 只是括号里的 1
```

```python
lst[0];  tup[-1]                     # 下标取（有序的都能下标）
x in st                              # set/list/dict(查键) 的"在不在"
dct.get("缺", "默认值")               # 为什么用 get：直接 [] 会 KeyError
for k, v in dct.items():             # 键值一起遍历；只写 dct 则遍历键
```

## 3. dict 高频固定写法（也是 agent 数据形状）

```python
# 建 + 增改
scores = {}
scores["张三"] = 92       # 键不存在=新增，存在=覆盖（同一行写法）
# 安全取
v = scores.get("张三", 0) # 给默认值，查不到不炸
# 经典计数套路（P1598 核心，以后统计一切）
freq = {}
for ch in line:
    freq[ch] = freq.get(ch, 0) + 1
# 嵌套访问（两层点名册）
roster["张3"]["hours"]   # 先外键后内键；层多时可逐层 .get
# 转有序视图
sorted(dct.keys())       # 键排序（P1598 按 A-Z 就要它）
```

## 4. 字符串清洗套路（判断/处理前先"洗"）

```python
s = input().strip().lower()      # 去首尾空白 → 变小写（一步链式）
words = s.split()                # 切词 → len(words) 就是词数
joined = "-".join(words)         # 反着粘回（split 的兄弟）
cnt = line.count(" ")            # 数空格（非空格字符 = len(line) - 空格数）
"123".isdigit()                  # 判断"是不是纯数字文本"（含负号/小数时小心）
# upper/lower 会返回新串：s = s.upper() 必须接住（字符串不可变）
```

## 6. 易混对照表（写完自查优先级最高）

| 混淆点 | 正确 | 错误/坑 |
|---|---|---|
| 赋值 vs 相等 | `==` | `=`（单等号在 if 里报错或行为怪） |
| input 类型 | `int(input())` | 直接拿文本当数 `'18'+1` 炸 |
| 大小写转换 | `s = s.upper()` | `s.upper()` 不接住=白干 |
| range 终点 | `range(1, n+1)` | `range(1, n)` 少了 n |
| 空集合 | `set()` | `{}`（那是空 dict） |
| 单元素元组 | `(1,)` | `(1)` |
| 字典取值 | `dct.get(k, 默认)` | `dct[缺的k]` → KeyError |
| 拆字符 vs 拆词 | `"12 34".split()` | 忘 split 直接处理整串 |
| 引号 | 英文半角 `"` `'` | 中文全角引号 → SyntaxError |
| 下标起点 | 第 1 个是 `[0]` | 从 1 开始数 → 越界/错位 |
