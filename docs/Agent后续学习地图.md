# Agent后续学习地图

> 2026-10-30。根据当前Python项目与学习记录整理，区分基础覆盖、尚未系统展开的主题及可选产品能力。本表不把所有方向变成当前必做项，不以静态实现替代独立掌握或运行证据。

## 1. 已覆盖的基础

现有主线已覆盖模型请求、流式解析、工具说明与参数校验、执行及结果回填、Agent循环、事件显示、上下文预算与摘要、会话保存恢复、AGENTS规则与Skill按需读取、CLI及HTTP/SSE入口。进阶前五节还覆盖了多会话、主动停止、模型模块拆分、只读策略及结构化结果和结束原因。

当前可以继续从这个基础扩展能力，无需为进入新主题重做上述局部验收。部分能力有实际使用截图，部分只有静态审阅；两者按原记录区分。

## 2. 尚未系统展开的方向

| 方向 | 已有基础 | 后续内容 |
| --- | --- | --- |
| 运行中控制 | 一次任务的工具循环、后台Task、/stop；运行中追加指令两入口已静态通过 | 后续任务队列、检查点与长任务恢复 |
| 模型适配与可靠性 | DeepSeek、统一结果、按用途配置、摘要/流式有限重试及输出边界、usage显示 | 多供应商协议与运行时模型选择、输出恢复、任务累计成本与延迟 |
| 上下文与记忆 | 按行读取、搜索、整体增量摘要、会话存档 | 保留近期多轮、滚动压缩、跨会话长期记忆与检索增强生成、会话分支 |
| 外部工具与安全 | 本地工具注册、路径限制、只读策略 | MCP外部工具接入、浏览器/数据库工具、按操作或路径授权、提示注入处理与执行隔离 |
| 任务编排 | 模型自主选择工具 | 明确步骤的工作流、规划/执行/检查、复杂任务分解、多Agent的上下文与职责协调 |
| 工程与产品 | Mock入门、命令行、HTTP事件流 | 成套回归与任务评测、链路记录、请求/会话并发隔离、部署与鉴权、界面和分发 |

会话树及JSONL已经讲过原理，这里指进一步实现；长期记忆则不同于把整段会话存盘，它还涉及选择、提取和再次检索有用信息。已有只读模式也是权限的一层基础，不等于全部执行隔离能力。

检索增强生成（RAG）指先检索相关资料，再把资料交给模型生成回答。MCP是用于连接AI应用与外部工具/数据的协议，参考[官方介绍](https://modelcontextprotocol.io/docs/getting-started/intro)。多Agent可以使用同一个模型，其区别在于上下文、职责和协调方式，并发请求本身不等于完整协作设计。

## 3. 建议顺序

运行中追加指令、[按用途配置模型](Agent进阶07_按用途配置模型.md)及[重试边界](Agent进阶08_模型请求的重试边界.md)均已于2026-10-30静态通过。当前接[MCP工具服务](Agent进阶09_MCP工具服务.md)，基于已有工具注册、异步和子进程知识，按独立服务端、客户端发现/调用、Agent接入的顺序展开。后续再按用途展开模型适配或知识检索；评测与运行记录结合新增行为安排，多Agent放在单Agent的职责与上下文边界更明确后。

这是针对当前项目的教学选择，不是所有Agent都必须采用的固定路线。[进阶第6节](Agent进阶06_运行中追加指令.md#9-本节完成结果)没有剩余必做代码项；静态结论与实际运行证据继续分别记录，不额外重复局部验收。
