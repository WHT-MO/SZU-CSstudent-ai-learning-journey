## 1. 先分清：网上的"新东西"是**四条不同的路**，不是一个清单

| 类别 | 例子 | 该什么时候学 |
|---|---|---|
| **① 语言本体进阶** | 装饰器、生成器 / 迭代器协议、上下文管理器、`async`/`await`、类型标注 `typing`、`dataclass` | **需要时才学**。S1 会碰到 `async` 的一小角；其余**大一下**补 |
| **② 工程实践** | `venv` 虚拟环境、依赖管理、项目结构、环境变量、日志 `logging`、调试器、测试 `pytest`、格式化 | **最该补的一层**——"会写脚本 → 能做项目"的分水岭；**S0 起边走边补** |
| **③ 第三方库** | `requests`（第一个）、`httpx`、`pydantic`、`rich`、`pandas`… | **用到才学**。库是耗材，不是学习目标 |
| **④ 计算机科学本体** | 数据结构、算法、操作系统、网络、数据库 | **不属于 Python**：学校课程 + 特别课 B + 大一下数据结构 |

**关键认知**：Python 的**语法很小，体积全在生态**（标准库 200+ 模块、PyPI 几十万个包）。**没有人"学完"过 Python**。网上那些"没学过的"，不是欠债清单，而是四条路上不同目标下的工具。

## 2. "基础完成了吗？" —— 分三层说才有意义

| 层 | 状态 | 判据 |
|---|---|---|
| **语法底座** | ✅ **已完成** | 能用二十来个已学工具，独立写出 ~90 行程序（`code/L13/jizhang.py`：类 + 文件存档 + 异常重试 + 按日期汇总 + `__main__` 入口），能算复杂度、能凭记忆画出结构图 |

→ 准确说法：**"17 课语法"收官了；Python 这条线刚进入"用"的阶段。**

## 4. 长期判据：看到新东西先问三句

1. **它属于上面哪条路？**（本体 / 工程 / 库 / CS）
2. **我现在的目标需要它吗？**（当前目标只有一个：**做出 agent v1**）
3. **我能用它做出什么？**——答不出具体用途，就记下名字，**放着**。

> **90% 的东西会被归到"以后要用到再学"——这就是正确处置，不是拖延。**
> 反面警告：**囤课/囤概念 = 能力错觉高发区**（本课程现有"资料精选 ≤5、不追视频"两条机制就是为此立的）。

## 5. 必做清单（三档，别混）

> ⚠️ 先纠正一个说法：现在是**自由时间 + 周节奏**（每周 ≥4 次），**所以没有"每日必做"的学习时段**。但其中**一条**值得独立出来按天做——因为它成本最低、复利最高。

### A. 每日（独立于"学习时段"，15–25 分钟）
1. **洛谷 1 题**（蓝桥杯同款题型）。**状态再差也只做这一条**——它是"不许归零"的保命线。
2. 做完**当天在洛谷看一次自己的提交记录**（AC 了看一眼用时/内存，WA 了看第一个错点）。

### B. 每次学习时段（≥45 分钟，每周 ≥4 次）
3. **主线 30–45 分钟**：S0–S3 期间 = agent 项目（粒度：**一次一个能验证的小增量**）。
4. **收尾 3 行笔记**：今天做了什么 / 卡在哪 / 下次第一件事（写进 `memory/03_会话纪要/` 或项目文档）。

### C. 每周（周日 10 分钟，固定仪式）
5. **周体检**：本周学了什么 / 欠什么 / 下周第一件事。
6. **回做 1 道旧题**：把以前 AC 过的题（如 P1980 / P1102）**不看旧代码重写一遍**——防手感退化，也是"真懂"的复检。
