# ⚡ 速查卡 L01 · 变量 / 类型 / 输入输出（3 分钟复习版）

## 一句话核心
> 程序 = 处理数据；**变量是贴了名字的盒子**，`print` 让程序说话，`input` 听你说话——但 `input` **永远返回字符串**。

## 关联概念（7 个，见关系图）
`变量` · `赋值 =` · `四种类型(int/float/str/bool)` · `print` · `input` · `类型转换 int()/float()` · `f-string` · `type()`

## 概念间关系
```
input("...") ──返回──▶ str 字符串 ──存进──▶ 变量(盒子)
                                                   │
       要做算术？必须过 int()/float() 转换器 ◀────┘
                                                   │
       要输出？用 f-string 拼接：f"你好，{name}"
```
- 类型决定"能做什么"：数字能 + - * /，字符串能拼接能切片，混用会报错
- `=` 是把右值**存进**左盒子，不是数学"等于"

## 真实应用案例
深大选课系统登录：`input` 收学号和密码（字符串）→ 后台校验 → 返回 `f"欢迎回来，{name}，你本学期选课 X 门"`；算绩点时要 `float()` 转换输入的成绩再求平均——不转就会 `ValueError`。

## 最常见误区（考试/面试最爱挖坑）
1. ❌ 以为 `input` 返回数字 → `'18' + 1` 直接报错
2. ❌ `print("1+1")` 以为输出 2 → 输出的是文本 `1+1`
3. ❌ 变量名用数字开头 / 中文 → `SyntaxError`
4. ❌ f-string 忘写 `f` 前缀 → 原样输出 `{name}` 花括号
5. ❌ 把 `=` 当数学等号 → 不理解 `age = age + 1`

## 快速自检题（5 道，先盖住答案）
1. `input()` 永远返回什么类型？要当数字用怎么办？
2. `int("3.14")` 会成功吗？`float("3.14")` 呢？为什么？
3. f-string 忘写 `f` 会输出什么？
4. 变量命名必须遵守哪三条规则？
5. 这段代码输出什么：`name="szu"` → `print(f"欢迎来到{name}!")` 如果输出里多出花括号原文，问题出在哪？

<details><summary>参考答案</summary>

1. 永远 `str` 字符串；用 `int(x)` / `float(x)` 转换
2. `int("3.14")` 报 ValueError（int 不认小数点文本）；`float("3.14")` 成功得 3.14
3. 输出 `{name}` 原样花括号（没被替换）
4. 英文小写+下划线；不能数字开头；不用中文/关键字
5. 正常输出 `欢迎来到szu!`；若出现 `{name}` 原文 = 少了 `f` 前缀
</details>
