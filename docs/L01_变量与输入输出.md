## 心智模型

**程序 = 菜谱**。变量是食材，print 是"端菜上桌"，input 是"问客人想吃什么"。
你写代码 = 写菜谱；电脑 = 照着执行的厨师（很听话，但也很死板）。

## 1. print —— 让程序说话

```python
print("hello, szu")
print("我是深大计软大一新生")
print(1 + 1)          # 数字不用引号
print("答案是", 1 + 1) # 英文逗号分隔，一次打印多个
```

三条规则：
- 文本要加引号（单双都行）；数字直接写
- `#` 后面是注释，写给人类看的，程序忽略
- 括号里的内容用**英文逗号**分隔可一次打印多个

## 2. 变量 —— 给数据起名字

```python
name = "张三"        # str   字符串
age = 18             # int   整数
height = 1.75        # float 小数
is_student = True    # bool  真/假

print(name, age, height)
```

- 变量 = 贴了标签的盒子，`=` 是把值**存进**盒子（不是数学里的等于）
- 命名：英文小写 + 下划线（snake_case），不能数字开头，不用中文
- 盒子内容可改：`age = age + 1` 读作"把 age 当前值加 1 再存回 age"
- 想看类型：`print(type(name))` → `<class 'str'>`

## 3. input —— 让程序听你说话

```python
name = input("你叫什么名字？")
print("你好，" + name)
```

⚠️ **本课最重要的坑**：`input` 返回的**永远是字符串**。输入 18 得到的是文本 `"18"`，不是数字 18。

```python
age = input("你多大了？")
age = int(age)          # 转换器：字符串 -> 整数
print("明年你", age + 1, "岁")
```

不转换的话 `"18" + 1` 会直接报错——这正是下方"试错练习"的素材。

## 4. f-string —— 推荐的拼接方式

```python
name = input("你叫什么名字？")
college = input("你是哪个学院的？")
print(f"你好，{name}！欢迎来到{college}")
```

`f` 放在引号前，`{}` 里的变量会被替换成它的值。**以后统一用 f-string，不用 + 拼接。**
