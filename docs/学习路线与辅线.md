## 做题策略：洛谷 vs 力扣

| | 洛谷 | 力扣 |
|---|---|---|
| 本质 | 竞赛训练场（OI/ACM/蓝桥杯同款） | 求职面试场（大厂笔试面试同款） |
| 题目形式 | 完整程序，自己写输入输出 | 填空函数，不用管输入输出 |
| 适用阶段 | 现在 → 2027-04 蓝桥杯省赛 | 大一下学完数据结构后开刷 |
| 新手入口 | 题单：入门1 顺序结构→分支→循环→数组→字符串 | Hot 100 / 面试 150 |

**规则一句话：打比赛去洛谷，找工作去力扣。** 蓝桥杯就是洛谷式 OJ，现在用洛谷等于提前模拟比赛。

## 辅线①：英语四级（2027-06 大一下考，不急）

- **军训期（现在）**：不备考。中午困就睡；四级 12 个月后才考，现在背词性价比极低
- **大一上（9–12 月）**：只做两件事——大学英语课照常上、期末别拖绩点后腿；有分级考/摸底就正常应对
- **大一上寒假 + 大一下 3–5 月**：四级主力备考期（核心词 + 真题 + 听力）
- **2027-03 前后**：报名（大一下场次）→ **2027-06**：考试，目标一次过 500+
- **2027-12（大二上）**：四级通过后无缝考六级

## 辅线②：计算机通识 —— 织入主线，不单开课

| 时机 | 织入内容 | 关联 |
|---|---|---|
| L01 | 内存里数据怎么存（变量 = 盒子 = 内存地址） | 变量与类型 |
| L02 起 | 报错搜索法：复制报错 → 搜索引擎 → 官方文档/Stack Overflow | 每次报错都是教材 |
| L10 | 硬盘 / 文件系统 / 绝对与相对路径 | 文件读写 |
| L12 | 操作系统、进程、环境变量、PATH（`where.exe` 当侦探 + 真敲不了的命令） | os 模块 |
| 特别课 A（开学后首个周末） | CPU / 内存 / 硬盘 / 程序怎么跑 + PowerShell 命令行 15 个命令实操 + 搜索技巧 | — |
| 特别课 B（国庆假期） | IP / 域名 / HTTP / 服务器 / 数据库 + 后端岗位全景图（为什么主线 Java/Go） | — |
