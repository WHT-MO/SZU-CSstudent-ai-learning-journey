# ⚡ 速查卡 L04+L05 · 列表 / 字符串 / tuple / set（3 分钟复习版）

## 一句话核心
> 数据容器四件套：**list 有序可改**、**tuple 有序不可改**、**set 无序唯一去重**、**字符串不可变**（方法都返回新值，要接住）。
> 输入处理铁律：`input()` 给一整条 → 按文本处理，或**先 `split()` 切块再 `map(int)`**，绝不直接对整串 `map(int, ...)`。

## 关联概念
`list` · `tuple` · `set` · `str 方法(lower/upper/strip/split/join/count/replace/isdigit)` · `len` · `split↔join` · `下标/切片` · `集合运算 | & -` · `map/int 转换`

## 概念间关系
```
文本一串: input() ──split()──▶ 列表 ──map(int)──▶ 数字列表
列表     ──join()────▶ 粘回文本     （split 与 join 是相反兄弟）
                ┌ list:  有序可改（scores[0]=95、append）
input 的数据 →  ├ tuple: 有序不可改（打包/防误改/当字典钥匙）(1,) 要逗号
                ├ set:   无序唯一（len(set)、sorted(set)、total-arrived=没到）
                └ str:   不可变（s.upper() 要接住；s 自己不变）
```

## 真实应用案例
军训点名：`missing = total_set - arrived_set`；去重统计：`len(set(nums))`；
成绩清洗：`input().strip().lower()`；P5015 标题统计：`len(line) - line.count(" ")`。

## 最常见误区
1. ❌ `s.upper()` 忘接住 → s 原样（不可变！）
2. ❌ 对整串直接 `map(int, words)` → `int('H')` ValueError；必须先 split
3. ❌ `set(nums)` 没 split → 按**字符**去重（逗号也算，`,,1,2,3` 惨案）
4. ❌ `(1)` 不是单元素元组，`(1,)` 才是；`{}` 是空 dict，空 set 写 `set()`
5. ❌ 叫 set 为"无序列表"→ 它无下标、不可重复、不能取第几个

## 快速自检题（5 道，先盖答案）
1. `len(set("1123"))` 是多少？为什么？
2. `s.strip().lower()` 会改变 `s` 吗？
3. tuple 和 list 唯一的关键区别是？
4. `set` 能不能 `s[0]`？为什么？
5. 输入 "12 34" 想得到两个整数，标准写法是？

<details><summary>参考答案</summary>

1. 3——set("1123") 把**字符**拆开去重 → {'1','2','3'}
2. 不会——字符串不可变，返回新串，要 `s = s.strip().lower()`
3. tuple 创建后不能增删改（list 可以）
4. 不能——set 无序、无下标，只能成员判断/遍历
5. `a, b = map(int, input().split())`
