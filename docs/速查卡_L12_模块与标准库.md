# ⚡ 速查卡 L12 · 模块 / 标准库 / PATH（3 分钟复习版 · 卡8）

> **一句话核心**：**`import` = 把别人写好的工具搬进来，用的时候带上模块名；路径要"跟着文件走"，不能"跟着人走"。**

## 1. 一句话核心
内建（`print` / `int` / `len` / `open`）开机就在；**标准库要 `import`**（`os` / `sys` / `json` / `math`）；**第三方要先 `pip install` 再 `import`**。  
路径：**`cwd` 是"人在哪"，`__file__` 是"文件在哪"** —— 存档要钉在脚本旁边，就用后者。

## 2. 关联概念
`import` · `from … import …` · `as` 别名 · 命名空间 · `pip` · 环境变量 **PATH** · `where.exe` · `os.environ` · `os.getcwd()` · `__file__` · `os.path.dirname` · `os.path.join` · traceback 读法
（前接：L10 文件读写 + cwd｜L11 类与对象 `self`）

## 3. 概念间关系（一张图）
```python
import os, sys                                    # ① 先搬工具：import 之前，名字不存在
print(sys.version)                                #    sys.executable = 正在用的是哪个 python
print(os.getcwd())                                # ② 人在哪（cwd，随你 cd 到哪儿而变）
print(__file__)                                   # ③ 文件在哪（这个 .py 自己，绝对路径）
p = os.path.join(os.path.dirname(__file__), "打卡状态.txt")   # ④ 拼成完整路径
with open(p, "w", encoding="utf-8") as f:          # ⑤ 用完整路径 → 不管在哪敲命令，都落在脚本旁边
    f.write("0 0")
```
- **`import` 之后才有这个名字**：忘了就 `NameError: name 'os' is not defined`。
- **`where.exe <命令>`** = 问系统"你会在哪些文件夹里找它"；找不到就是没命中。
- **PATH 只负责"去哪找"，不保证"那里有"**（`D:\app\Java\bin` 在清单里，可里面没 `java.exe`）。
- **相对路径跟 cwd 走**；要跟脚本走必须用 `__file__` 那一套。

## 5. 常见误区
1. ❌ 忘了 import / import 之前就用 → `NameError: name 'os' is not defined`（**不是** `ValueError`）。
2. ❌ 以为"PATH 里有这个文件夹"就能用 → 文件夹在清单里，但里面**没有那个程序**，照样找不到。
3. ❌ `sorted(N)` 不接返回值 → 打印出来还是乱序；`N.sort()` 返回 `None`（原地改）。**有返回值的函数必须有人接。**
4. ❌ `" ".join(x)` 里 `x` 是单个数字 → `TypeError: 'int' object is not iterable`；且元素**必须全是 `str`**（数字先 `map(str, …)`）；`join` 是**分隔符**的方法。
5. ❌ 想让存档"跟脚本走"却用相对路径 → 它跟的是 **cwd**，换个目录跑就落到那边去。
6. ❌ 硬编码 `"D:\code\..."` → 要写 `r"..."`（`\` 有转义含义），而且换文件夹 / 换电脑就崩。
7. ❌ 看 traceback 只看第一行 → 先看**最后一行**（什么错），再扫**有没有你的文件名**（没有 = 是"跑它的方式"的锅）。
8. ❌ 对照验收不先对齐初始状态 → 两边"起跑线"不同，比出来的差异是假的。
