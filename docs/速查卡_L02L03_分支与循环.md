# ⚡ 速查卡 L02+L03 · 分支与循环（3 分钟复习版）

## 一句话核心
> 程序流程只有两种"高级动作"：**if 是岔路口（选一次）**，**循环是绕圈（重复干）**；
> 循环里嵌 if 就能"边重复边做决定"。

## 关联概念
`bool/比较/逻辑(and or not)` · `if/elif/else` · `while` · `for + range` · `break` · `continue` · `累加器` · `嵌套循环` · `死循环`

## 概念间关系
```
if 成立? ─是─▶ 干活 → 下班（elif/else 不看）
  │否 → elif 成立? ─是─▶ ... → else 兜底      ← 从上往下，第一个成立生效

while 条件为真: 一直绕圈（次数未知，靠计数器停下）
for i in range(a, b): 数着走 a..b-1（次数已知）  ← 前闭后开!
   └─ 循环内可嵌 if；break=整圈撤出，continue=只跳本次
累加器: total = 0 → total = total + i → 求和/计数的万能套路
```

## 真实应用案例
- 成绩等级判断器（elif 链）｜深大选课系统判绩点档位
- 14 天军训每日统计训练小时（for + 累加器）
- 猜数字游戏（while True + break）
- 九九乘法表（嵌套循环：外层走一步，内层走一圈）

## 最常见误区
1. ❌ `range(1, 10)` 以为含 10 → **前闭后开**，想含 n 写 `range(1, n+1)`
2. ❌ while 忘改计数器 / 忘推进条件 → **死循环**（Ctrl+C 救命）
3. ❌ `=`（装进盒子）与 `==`（等于吗）混用
4. ❌ break（退出整个循环）与 continue（只跳过本次）分不清
5. ❌ if 行末忘冒号 / 循环体忘缩进
6. ❌ 以为 elif 和 if 是并列的 → elif 只在**前面全不成立**时才被问

## 快速自检题（5 道，先盖住答案）
1. `range(1, 5)` 会数出哪几个数？
2. 死循环是怎么发生的？怎么中断？
3. break 和 continue 各用一句话怎么说？
4. 下面打印什么：`for i in range(3): print(i)`（注意起点）
5. `if a:` 和 `while a:` 的行为差别在哪？

<details><summary>参考答案</summary>

1. 1,2,3,4（不含 5）
2. 条件永远 True 且没人让它变 False；按 Ctrl+C
3. break=立刻退出整个循环；continue=跳过本次剩下的，进入下一次
4. 0,1,2（range(3) 从 0 开始）
5. if 只检查一次走一条路；while 检查→执行→再检查→…直到条件 False
</details>
