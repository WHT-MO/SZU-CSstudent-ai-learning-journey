# ⚡ 速查卡 L06 · 字典 dict（3 分钟复习版）

## 一句话核心
> dict = 点名册：用"键"直接取"值"。**= 左边是写（键不存在自动开页），= 右边/读取用 [] 遇不存在键会炸（KeyError）→ 安全读用 `.get(键, 默认)`。**

## 关联概念
`键→值` · `{}`空dict（不是空set！）· `.get/in/items/del/len` · 键须可哈希(str/int/tuple；list不行) · 嵌套 · 计数套路 · `dict ≈ JSON`（agent 预备）

## 概念间关系
```
list: 按下标取（第几个）      dict: 按键取（叫什么名字）
遍历 dict 默认拿到的是【键】；要值用 .values()（待解锁）或 .items() 键值一起
freq[ch] = freq.get(ch,0)+1   ← 计数套路：读旧值(无则0) → +1 → 写回（开页/更新）
dict 嵌套 = 先外键后内键：roster["张3"]["hours"]
```

## 真实应用案例
通讯录按姓名查电话（键=姓名）；P1598 统计字母频次（键=字母，值=次数）；
未来 agent：给 LLM 的参数/工具返回就是 dict/JSON 结构。

## 最常见误区
1. ❌ `{}` 当空集合（那是空 dict；空 set 写 `set()`）
2. ❌ `dict[不存在的键]` → **KeyError**；安全读用 `.get(键, 默认)` 或先 `in`
3. ❌ 用 list/set 当键 → TypeError（键须可哈希）
4. ❌ 以为遍历 dict 拿到的是值 → 拿到的是键
5. ❌ 混淆读写方向：`= 左边 freq[k]=写` vs `读取时 [] / .get`

## 快速自检题（5 道，先盖答案）
1. `{}` 是空的 ___；空集合要写 ___。
2. `d = {"a":1}`，`d["b"]` 会怎样？`d.get("b", 0)` 呢？
3. 下面哪个能当键：`"name"`、`(1,2)`、`[1,2]`、`3`？
4. `for k in d:` 里 k 是什么？
5. 计数套路里 `.get(ch, 0)` 的 0 是干嘛的？

<details><summary>参考答案</summary>

1. dict；set()
2. 抛 KeyError；返回 0（不报错）
3. "name"、3、tuple (1,2) 可以；[1,2]（list）不行
4. 键（要键值一起用 .items()）
5. 默认值：ch 第一次出现时"现在算 0 次"，保证不 KeyError
</details>
