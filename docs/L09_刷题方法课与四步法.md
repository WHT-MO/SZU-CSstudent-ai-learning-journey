## 1. 四步法（解题的固定流水线）

| 步 | 干什么 | 产出 |
|---|---|---|
| ① | **看输出** | 四个维度：几个值 / 什么格式 / 什么类型 / 有没有多余文字 |
| ② | **看输入** | 几个什么、几行、范围多大 |
| ③ | 想清楚用什么装 | **数据结构** |
| ④ | 排好怎么走 | **实现步骤**（含循环条件） |

- **第 ① 步是四个维度，不是"看一眼"**：P1598 就栽在"格式"上（每行末尾多一个空格）。
- **第 ③④ 步必须产出不同的东西**才算有效——"过程怎么实现"和"设计步骤"这种说法等于两步做了一件事。

### 本课的复述检验

- 首答："1 看输出 / 2 看输入 / 3 过程怎么实现 / 4 设计步骤" → 第 3、4 步**笼统且近义** → 判**不合格**。
- 追问后补答："**第 3 步产出数据结构，第 4 步产出实现步骤**" → ✅ 通过。
- **落地口径**：学员要求"四步法在脑子里过就行，写下来浪费时间"——同意，但**保留"数据结构 + 循环条件"两行必须落纸**（这正是第 3、4 步的产出物）。

## 2. 第 1 题：P1980 计数问题 —— 两次 TLE 的诊断

题意：给 `n` 和 `x`，数 1..n 的十进制写法里数字 `x` 一共出现多少次。

| 版本 | 写法 | 结果 |
|---|---|---|
| A | 把 1..n 的所有数字字符**攒进一个列表**，再遍历数 | 小数据 AC / 大数据 **TLE**（n = 10⁶ 时列表约 **600 万元素**，而且跑两趟） |
| B | 一趟遍历 + 计数器（逐位 `int(b) == x`） | **本机 0.39s**，洛谷**仍 4 点 TLE** |
| C ✅ | 循环外 `x = str(x)`，逐位**字符比较** | **本机 0.15s** → 洛谷 **AC** |

**实测对照**（本机，输入 `1000000 0`，结果都是 488895）：三种写法约 **0.39s / 0.15s / 0.09s**——最慢的是中间容器那一版，最快的是让 `''.join(...) + .count(...)` 干活的版本（本次未采用，保留最直观的逐位比较）。

**三条能带走的结论：**

1. **`n ≤ 10⁶` 是提示**：题目给大范围就是让你"**能不存就不存**"——中间容器往往是 TLE 的元凶。
2. **算法对 ≠ 一定过**：Python 层每一次动作都贵，把重活交给 C 实现的 `.join()` / `.count()` 能快一个数量级。
3. **评测机比本机慢**：本机 0.39s 在洛谷**照样 TLE**。

> 教员当场也犯了一个错并撤回：曾推测"洛谷对 Python 有时限放宽"——**这是未核实的推测**。没核实的话不写进结论（证据纪律）。

### 成品代码地图 `code\L09\p1980.py`（25 行）

- 第 18 行 `z,x = map(int,input().split())`：读入两个数。
- 第 19–20 行 `t = 0`；`x = str(x)`：**把 `x` 变成文字放在循环外**（每圈都 `int(b)` 太贵）。
- 第 21–24 行：外层走 1..n，内层 `for b in str(a)` 拆每一位，`if b == x` 计数器 `+1`（**字符比字符**）。
- 第 25 行 `print(t)`。

## 3. 第 2 题：P1420 最长连号 —— AC 之后才露馅的 bug

题意：给 n 个数，求最长的一段"后一个 = 前一个 + 1"的连续段长度。

| 版本 | 问题 | 结果 |
|---|---|---|
| A | `for b in range(n)` 里用 `a[b-1]` → **b = 0 时 `a[-1]` 绕到末尾**，把"最后一个数 + 1 == 第一个数"当成"接着" | 洛谷 **AC 属运气**；教员构造 `6` / `6 1 8 2 9 5`（真答案 1）实测输出 **2** → 露馅 |
| B | 想跳过第一轮，却写了 **`break`** | **更糟**：第一轮就把整个循环掐死，`n > 1` 全部只输出 1（原样例 `1 2 3 5 6 7 8 10` 输出 1） |
| C ✅ | 改成 **`continue`** | 六个用例全过（含 `6 1 8 2 9 5` = 1、样例 = 4、n=1 = 1、整串连号 = 5） |

**两个可以带走的坑：**

1. **Python 的负下标 `a[-1]` 合法、不报错**——它绕到最后一个元素。所以"**不报错的错**"比报错难查得多。规矩：凡写 `a[i-1]` 而 `i` 可能为 0，先警惕。
2. **`break`（撤整圈）vs `continue`（跳本次）**——这条在速查卡 §6 坑 4 里教过、考过，今天原样又撞上。

### 09-14 的复修（欠账销账）

09-13 验收时把 P1420 `n=1` 的两行输出**看成了一个答案**。09-14 复验才发现：`n = 1` 时会**打印两行**（循环里打一次、循环外 `print(max)` 又打一次）。
修法：**删掉循环里的 `n == 1` 分支**——正确答案本来就在 `max` 的初值 1 里。修完 **8 组用例全过**，入库 `code\L09\p1420.py`。

### 成品代码地图 `code\L09\p1420.py`（42 行）

- 第 29–32 行：读入 `n`、列表 `a`，两个变量分工——`long` = 当前段长（断了就归 1），`max` = 历史最长，**初值都是 1**。
- 第 33–35 行：`for b in range(n):` 里，**`if b == 0: continue`**（跳过第一轮，因为第一个数没有"前一个"可比）。
- 第 36–39 行：`elif a[b-1] + 1 == a[b]:` 接上了 → `long + 1`，顺手更新 `max`。
- 第 40–41 行：`else: long = 1`（断了重来）。
- 第 42 行 `print(max)`。
