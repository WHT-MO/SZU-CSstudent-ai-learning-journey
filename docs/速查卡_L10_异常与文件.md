# ⚡ 速查卡 L10 · 异常与文件（3 分钟复习版 · 卡6）

> **一句话核心**：**文件 = 硬盘上的抽屉**：`with open(路径, 模式, encoding="utf-8") as f` **开门干活、出门自动关门**；`try / except` **只抓你预期的那一种错误**。

## 1. 一句话核心
打开 → 读 / 写 → 自动关。模式：`"r"` 读（文件不在就报错）、`"w"` **清零重写**、`"a"` 追加；判据是 **状态快照用 `"w"`，日志才用 `"a"`**。读之前先想好"文件不在怎么办" → `try / except FileNotFoundError`。

## 2. 关联概念
`with` / `open` / `encoding` · 模式 `"r"` `"w"` `"a"` · `f.read()` / `f.write()` · `\n` 自己写 · `try` / `except 具体类型` · `FileNotFoundError` / `ValueError` · 编码 utf-8 / gbk / utf-8-sig · 相对路径 & **cwd** · 读档模板 `map(int, f.read().split())` · 状态住两处（内存 + 文件）
（前接：L04 输入模板——同一套动作，只换了数据来源｜L08 打卡程序的"不存盘"缺口｜后续：L11 把状态收进对象）

## 3. 概念间关系
```python
try:                                                     # 试着读档
    with open("打卡状态.txt","r",encoding="utf-8") as f:    # "r" 读；文件不在会报错
        last, d = map(int, (f.read().split()))           # read 整串读回 → split 拆开 → 变成两个整数
except FileNotFoundError:                                # 只抓"文件不存在"这一种
    last, d = 0, 0                                       # 新用户：last = 0 是哨兵值（从未打卡）
    print("还没有存档，这是第一次运行")

with open("打卡状态.txt","w",encoding="utf-8") as f:       # "w" = 先清零再写（存状态快照）
    f.write(f"{last} {d}")                               # 写回当前状态；write 不会自动换行
```
- **`with` 专管开关门**：出门（含中途出错）自动关，不用手写 `f.close()`。
- **`"r"` 找不到文件 → `FileNotFoundError`**：把它变成"新用户分支"，程序就不会一启动就崩。
- **`"w"` 是清零重写**：连着两次 `"w"`，只会剩后写的那一份。
- **状态同时住在内存和文件两处** → 只改一边，另一边会在退出时把旧值写回去，**改动等于没做**。

## 5. 常见误区
1. ❌ 清空写成 `f.write("")` → 下次启动读回空内容、拆不出两个值 → **`ValueError: not enough values to unpack`**（正确做法：写 `"0 0"`，不是写空文件）。
2. ❌ 想"接着写"却用了两次 `"w"` → 第二次 `"w"` 一开门就**清零**，只剩后写的；追加要用 `"a"`。
3. ❌ 直接 `open(不存在的文件, "r")` 不管 → **`FileNotFoundError`**（要么先判断，要么 `try` 抓它）。
4. ❌ 只改文件不改内存（或只改内存不写文件）→ 退出时旧值被写回，**清空 / 修改等于没做**。
5. ❌ 读写两端编码不一致（`gbk` / `utf-8` 混用）→ **乱码**：文件**没坏**，是写和读拿了不同的"对照字典"。
6. ❌ 以为相对路径跟着脚本走 → 它跟的是 **cwd**（敲命令时所在的目录），换个目录跑文件就落那边。
7. ❌ 写裸 `except:` → 把**你自己的 bug**一起吞掉，永远找不到错；只抓预期类型（本例只抓 `FileNotFoundError`）。
8. ❌ 忘了 `\n` → `write` **不会**自动换行，多行内容会粘成一行。

<details><summary>答案（想完再点开）</summary>

1. `"r"` 读（文件不在就报错）、`"w"` 清零重写、`"a"` 追加；**状态快照用 `"w"`**（`"a"` 留给日志/流水账）。
2. `FileNotFoundError`；用 `try / except FileNotFoundError` 处理（通常当作"新用户，还没存档"）。
3. `abcdef`——`write` **不会自动换行**，想换行必须自己写 `\n`。
4. 因为中文 Windows 默认编码是 GBK，写和读两端必须用同一本"字典"；**乱码不是文件坏了**，是写和读用了不同的对照字典。
5. 相对 **cwd**（敲命令时所在的目录），不是脚本所在目录；换个目录跑，文件就落在那个目录里。
