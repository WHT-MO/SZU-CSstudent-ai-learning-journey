## 心智模型

**函数 = 一台料理机**。`def` 是"把机器造出来放好"——造完什么都不会发生；**写 `名字(...)` 才是按下开关**，机器才开始转。

好处有两个：① 同一段活不用抄第二遍；② 想改逻辑只改机器内部一处，所有调用的地方一起变。

## 1. def —— 造工具 ≠ 用工具

`code\L07\day7_func.py` 第 2–8 行：

```python
def average(a, b, c):        # 第 2 行：造机器；a b c 是参数（机器上的进料口）
    total = a + b + c        # 第 3 行：函数体——缩进的这几行，每次调用整段跑一遍
    return total / 3         # 第 4 行：交货，把算出来的结果递出去
print(average(90,80,100))    # 第 5 行：调用 → 90.0
x = average(70,60,50)        # 第 6 行：结果接住存进 x → 60.0
print(average(x,90,60))      # 第 8 行：x 当成普通值再喂进去 → 70.0
```

- **只写 `def` 不调用，程序什么也不做**（机器摆着不用）。
- 参数是"进料口"：`average(90,80,100)` 里的 90 80 100 进去，函数里就叫 `a b c`。
- 函数体是**缩进的那几行**；缩进一结束，函数就完了。

## 2. return vs print —— 交货 vs 喊话

这是本课最重要的一条。`day7_func.py` 第 10–18 行：

```python
def f1(a,b):
    print(a + b)          # 只"喊给人听"，屏幕上出现 3，但函数没交货
def f2(a,b):
    return a + b          # 交货：把 3 递出去
f1(1,2)                   # 第 15 行：屏幕打印 3
r1 = f1(1,2)              # 第 16 行：屏幕又打 3；但 r1 接到的是 None
r2 = f2(1,2)              # 第 17 行：r2 = 3
print(r1,r2)              # 第 18 行：打印 None 3
```

因果链：**`print` 的输出是"给人看的"，不是"给程序用的"**——它不回传任何东西。函数没写 `return` 时，Python 自动交一个 `None`（空、什么都没有），所以第 16 行的 `r1` 是 `None`。

`.append` 是同一族：**只做事、不交货**（调用处拿到 `None`）。

## 3. 返回多个值：打包成元组，拆包接住

`day7_var.py` 第 2–5 行：`return x,y` 会把两个值**打包成一个元组**。第 8 行用两个变量接住：

```python
def week(days):          # 第 2 行
    x = days // 7        # 第 3 行：满几周（// 是整除）
    y = days % 7         # 第 4 行：余几天（% 是取余）
    return x,y           # 第 5 行：打包成 (x, y) 交出去
w,d = week(b)            # 第 8 行：拆包接住——w 拿第一个，d 拿第二个
print(a,w,d)             # 第 9 行：姓名 + 满周数 + 余天数
```

作业实测（2026-09-12 学员自己跑通）：

| 输入 | 输出 |
|---|---|
| `xiao 10` | `xiao 1 3` |
| `xiao 14` | `xiao 2 0` |
| `xiao 1` | `xiao 0 1` |

这个"打包 / 拆包"不是新东西——和 L05 的 `a, b = input().split()` 是**同一套动作**（那次是学员自己迁移过来的）。

## 4. 作用域：函数里造的变量是"临时工"

`day7_func.py` 第 20–23 行：

```python
def g():
    inner = 10        # inner 只在函数体里活着
g()
#print(inner)  没定义   # 第 23 行：出了函数，inner 就没了
```

- 函数体里造的变量，**出了函数就消失**（像请来的临时工，干完就走）。
- 所以函数内外的同名变量**互不打架**：里面的 `x` 和外面的 `x` 是两个盒子。

## 5. 当天追问的 5 个机制（每个都在关节上）

1. **为什么 `270/3` 是 `90.0` 不是 `90`**：`/` 除法**永远**给小数（float），想整除用 `//`。
2. **为什么 `-7//2` 是 `-4`**：`//` 是**向下**取整（往更小的方向），而 `int()` 是**砍向 0**；配套 `-7 % 2` 是 `1`。两个方向不一样，负数时最容易晕。
3. **为什么 `greet("小明")` 要加引号**（第 25–27 行）：加引号 = 这是一段文字值；不加引号 = Python 去找一个叫"小明"的**变量**，找不到就 `NameError`。
4. **为什么 `r1` 是 `None`**：见上面 §2——函数没 `return` 就自动交 `None`。
5. **`" ".join(map(str, ...))` 里要不要再套一层 `list()`**：**不需要**。`join` 接受任何"能一个一个取出来"的东西。作业第 17 行就是没套 `list()` 的写法。

## ⚠️ 当天真撞过的 4 个坑

1. **`return x` 只交了一半**——算了 `x`、`y` 两个，只把 `x` 递出去；另一个怎么都拿不到（拿到 `None`）。口头自检："我算了几个？交了几个？"
2. **`print(week(b))` 把元组原样倒出来**：屏幕上出现 `xiao (1, 3)`——**容器的长相 ≠ 它的内容**。这是第二次撞同族的坑（第一次是 `print(freq)` 直接把整个字典倒出来）。
3. **`print(a, " ", week(b))` 多出一个空格**：`print` 用逗号分隔时**自己会插一个空格**，别再手写 `" "`。
4. **`函数() = 值`** → `SyntaxError: cannot assign to function call`（上一轮作业里写过这种写法）。原因：`=` 左边必须是"能装东西的东西"（变量），函数调用的结果是"值"，不能反过来装。
