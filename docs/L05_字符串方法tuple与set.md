## 1. 字符串方法：挂在文本上的功能

方法 = "数据自带的功能"，写法 `变量.方法()`。常用：

```python
s = "  Hello, ShenZhen 2026  "
s.lower()          # '  hello, shenzhen 2026  '  全小写
s.upper()          # 全大写
s.strip()          # 'Hello, ShenZhen 2026'      去掉首尾空白（军训读输入神器）
s.split()          # ['Hello,', 'ShenZhen', '2026']  按空白切（复习咒语）
s.count("e")       # 统计出现次数
s.replace("ShenZhen","SZ")   # 替换
s.startswith("  H")  # True
"abc123".isdigit() # False；"123".isdigit() → True
```

- `len(s)` 是函数（`len(字符串)`）；`s.upper()` 是方法（挂着的）。
- ⚠️ **字符串不可变**：`s.upper()` 返回**新字符串**，`s` 自己不变！要生效必须接住：`s = s.upper()`
- `split` 与 `join` 是一对相反操作：split 把字符串切成一串，join 把一串粘回字符串：
  ```python
  words = ["深大", "计软", "大一"]
  "-".join(words)      # '深大-计软-大一'（用 - 粘）
  "".join(words)       # '深大计软大一'
  ```

## 2. tuple：贴了封条的列表

```python
point = (3, 5)        # 坐标：打包
x, y = point          # 解包 → x=3, y=5
a, b = 1, 2           # 这也是 tuple 打包/解包（圆括号可省）
point[0]              # 3，能读
# point[0] = 9        # ❌ TypeError：不能改！
```

- 和 list 一样有序、可下标，但**创建后不能增删改**（不可变）。
- 用途：① 打包返回多个值（`map(int, ...)` 解包背后就是它）② 数据不想被意外改（安全）③ 后面能当字典的钥匙（list 不行）。
- ⚠️ 单元素元组要加逗号：`(1,)`；`(1)` 只是括号里的 1。

## 3. set：自动去重的磁贴盒

```python
nums = [3, 1, 2, 3, 1]
s = set(nums)          # {1, 2, 3}  自动去重
list(s)                # 转回列表
```

- **无序**（别按下标！）｜**唯一**（自动去重）｜**查得快**（"在不在"像查字典，O(1) 级）。
- 集合运算：并 `|`、交 `&`、差 `-`：

```python
total = {"小明","小红","小刚"}       # 全班
arrived = {"小明","小刚"}            # 已到
arrived  # 没到的 = total - arrived → {'小红'}
```

- 常用套路：`len(set(列表))` 数不同值；`sorted(set(列表))` 排序去重。
- ⚠️ `{}` 是**空字典**不是空集合；空 set 要写 `set()`。set 里不能放 list（元素必须"可哈希"）。

## 4. 三兄弟对比

| | list | tuple | set |
|---|---|---|---|
| 有序？ | ✅ | ✅ | ❌ |
| 可改？ | ✅ | ❌ | ✅（但元素唯一） |
| 按下标取 | ✅ | ✅ | ❌（用成员判断） |
| 典型用途 | 一堆要改的数据 | 打包/不可变数据 | 去重、查在不在、集合运算 |

## 5. 真实案例：军训点名

```python
total = {"小明", "小红", "小刚", "小丽", "小强"}
line = input("已到的人（空格分隔）：")
arrived = set(line.split())
missing = total - arrived
print("没到的：", "、".join(missing) if missing else "全员到齐")
```

## ⚠️ 本课最易错 5 条

1. `s.upper()` 忘了接住 → s 还是原样（字符串不可变）
2. `split` 和 `join` 方向搞反
3. `(1)` 不是单元素元组，`(1,)` 才是
4. `{}` 是空 dict，不是空 set
5. set 无序无下标：`s[0]` 会报错

**12 岁版**：字符串是**写好的字条**——想改内容只能重新写一张，原来的不能涂改；tuple 是**贴了封条的盒子排**——能看里面有什么、但不能塞新东西也不能抽走；set 是**一盒磁贴**——长得一样的磁贴自动吸成一块（去重），贴得乱糟糟没有顺序，但你找"有没有这张"特别快。
