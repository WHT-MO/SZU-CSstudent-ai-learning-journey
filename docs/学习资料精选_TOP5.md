# 📚 学习资料精选 TOP5（按需取用，别全看）

> 挑选标准：**不看名气，看"和你的路线是否咬合、是否唯一不可替代"**。
> 军训期主渠道仍是教员（讲义+手打+review），资料只做"第二讲解"与"备查"。

## TOP 5

### 1️⃣ Python 官方中文教程（docs.python.org/zh-cn/3/tutorial）—— 主备查
- **适合谁**：所有人，特别是遇到语法疑问时
- **难度**：★☆☆（阅读门槛低）｜**时间**：按需查，每次 5–10 分钟
- **最值得看**：数据类型、控制流、函数、类 四章
- **可跳过**：模块打包/虚拟环境等工程细节（前期用不上）
- **为什么入选**：唯一权威、永不淘汰、免费——它是"字典"，不是"课本"

### 2️⃣《Python编程：从入门到实践》（最新中文版）—— 系统书（可选第二讲解）
- **适合谁**：喜欢翻书系统自学、想看我讲义之外另一种叙述的人
- **难度**：★☆☆ ｜**时间**：40–60 小时（建议散在 10–12 月，不是军训期）
- **最值得看**：前半基础 + "外星人入侵"和"数据可视化"两个项目
- **可跳过**：Django Web 部分（你的主线以后是 Java/Go，不是 Python Web）
- **为什么入选**：全书一以贯之做项目，能补"从语法到成品的桥梁"

### 3️⃣ 翁恺《程序设计入门——C语言》（中国大学MOOC/国家智慧教育平台）—— 学校 C 课的救援队
- **适合谁**：开学后 C 语言课跟不上、或想拿高绩点的你（**非军训期使用**）
- **难度**：★★☆ ｜**时间**：10 月–12 月，每周 3–5 小时
- **最值得看**：数组与字符串、指针、结构体、文件
- **可跳过**：偏冷门的课后拓展题
- **为什么入选**：学校课用什么你就配什么——这是 C 课刚需，不是爱好

### 4️⃣ 洛谷"入门"系列题单（顺序结构→分支→循环→数组→字符串→函数）—— 练习主战场
- **适合谁**：你，从 9/10 起到 2027-04 蓝桥杯
- **难度**：★☆☆ 起步 ｜**时间**：每晚 20–30 分钟（教员挑题）
- **最值得做**：按题单顺序刷，题单=你语法进度的"试卷版"
- **可跳过**：题单里偏数学构造的难题、红题单的烧脑题（蓝桥杯省二用不上）
- **为什么入选**：蓝桥杯=洛谷式 OJ，这是唯一能直接转化成比赛成绩的资料

### 5️⃣ Harvard CS50x（edX 免费 / B站中字）—— 已降级：课余兴趣（2026-09-08 决策）
- **适合谁**：想搞懂内存/抽象/计算机底层、顺带练英语听力的人（你已降为"想听就听"的课余项）
- **难度**：★★★（全英 + 前半用 C）｜**时间**：非计划内，不设时间预算
- **最值得看**：Week0–5（C、内存、算法）＋ Week6 的 Python 对比
- **可跳过**：全部 psets；Web 方向后几周
- **为什么降级**：英语学习改由 agent 项目英文文档 + 四级承担，效率更高；CS50x 不再排进任何计划阶段（原"寒假系统刷"取消）

## ⚠️ 看似有价值、实则不值得大量投入的资料

| 资料 | 为什么是坑 |
|---|---|
| 「7 天 / 21 天精通 Python」速成书与短视频 | 贩卖焦虑、零深度；看完依然不会写 |
| B站几百集「全套 Python 教程」收藏夹 | 囤积 ≠ 学习；被动看视频性价比极低，你要的不是更多视频 |
| 《流畅的 Python》现在精读 | 好书但面向有经验者，现在读 = 挫败；排到大二 |
| 力扣会员提前硬刷中等/难题 | 力扣是"数据结构学完后的面试战场"，现在刷 = 浪费 + 打击自信 |
| 付费"后端就业班"/训练营大一就报 | 官方免费资料已足够；割韭菜高发区，至少大三前不需要 |
| 刷面经/八股文 | 时机完全不对，面试知识有保质期，大二大三再背 |
| 「学习路线图合集」收藏帖 | 收藏即吃灰；你已经有本仓库这套闭环，不缺地图缺执行 |

## 三条铁律
1. 一个主题只听一个老师（主渠道=教员，资料只做补充）
2. 视频一律 1.5 倍速，先动手再回看
3. 收藏前问自己：这周用得上吗？用不上就不收藏
