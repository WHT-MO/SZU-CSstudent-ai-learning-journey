# ⚡ 速查卡 L11 · 类与对象（3 分钟复习版）

> **一句话核心**：**类是说明书，对象是按说明书造出来的实物**；**数据住对象，方法住类**。

## 1. 一句话核心
`class` 定义"这种东西**有哪些栏位**（属性）、**会做哪些事**（方法）"；`对象 = 类()` 造出来，**每个对象自带一份数据**。

## 2. 关联概念
`class` · `__init__` · `self` · 实例属性 · 方法 · 实例化 `Kaoqin()` · 实例属性 vs 类属性
（前接：L07 函数与作用域 / L10 文件读写——本课把"全局变量到处被改"改成"状态住对象"）

## 3. 概念间关系（一张图）
```python
class Kaoqin:              # 说明书：只写"有哪些栏位 + 会做哪些事"，自己不存数据
    def __init__(self):    # 造实物时【自动】跑这一趟
        self.last = 0      # 往"这个实物"身上挂一栏
    def see(self):         # 方法：第一个参数永远是 self（调用时不传）
        print(self.last)

data = Kaoqin()            # 按说明书造实物（这一步才真的跑 __init__）
data.see()                 # 让这个实物做它会的事（data 自动变成 self）
```
- **`self` = 这个对象自己**；`self.last` = 它身上的 last 栏 —— **`self` 和 `self.last` 不是一回事**。
- 类身上**只有方法**，没有对象的数据（昨天实测：`Dog.__dict__` 里只有方法，`Dog.name` 取不到）。
- 方法里不带 `self` 的名字按 **局部 → 外层 → 全局** 找；全都没有才 `NameError`；**全局恰好有同名 → 静默用错值**（最难查）。

## 4. 真实案例
`code\L11\kaoqin.py`（打卡程序类版）：`last` / `d` / `today` 三个属性 + 8 个方法。
对照 `code\L10\kaoqin.py` 看差别：`check()` 从"偷读全局 `last`"变成"`self.last` / `self.today` —— 来源写在脸上"。

## 5. 常见误区
1. ❌ "对象在类里" → 类里没有对象；**同一个类造出的多个对象，各带一份数据**（图纸上停不了车）。
2. ❌ 忘了 `self.`（写成 `last = today`）→ `NameError: name 'last' is not defined. Did you mean: 'self.last'?`；
   **先读后写同一个名字** → `UnboundLocalError: cannot access local variable ...`。
3. ❌ 拿**类属性**当状态（`class Kaoqin: bag = []`）→ 可变类型**所有对象共用一份**（一个对象 append，另一个也有）；
   数字类型则在赋值时悄悄变成实例属性 —— 时共享时不共享，最迷惑。
4. ❌ `__init__` 名字拼错 / 造对象忘传参 → `TypeError: Kaoqin() takes no arguments` / `missing 1 required positional argument`。
5. ❌ 风格：`F"{...}"` 大写 F 合法但不合习惯；**类名**用大驼峰 `Kaoqin`、**方法/变量**用小写+下划线。

1. 就是刚造出来的那个新对象（也就是 `data`）。
2. 不一样：左边是"**对象身上那一栏**"（`self` 是对象，`.last` 是栏位名），右边是 **`__init__` 的参数**（一趟性的值）。
3. 会。`[]` 是**可变**类属性，两个对象共用同一个列表；状态要用 `self.xxx` 挂到各自对象上。

5. 因为**依赖来源写在脸上**：`self.last` 一眼看出"这是这个对象的状态"；全局变量则让任何函数都能偷偷读写它。
