## 1. 一句话核心

> **工作量 = 每一层的圈数乘起来，再把所有情况加起来。**
> **"双层"不是罪名，n 才是。**

---

## 2. 三种形状（全部取自学员自己写过的代码）

| 形状 | 出处 | 内层圈数 | 总圈数 | 记号 |
|---|---|---|---|---|
| **A** 内层跟着外层走 | `code/L09/p1980.py` 第 21–22 行 `for a in range(1,z+1): for b in str(a)` | 不固定，a 几位跑几圈，平均 **5.89** | ≈ 5.89n | **O(n)** |
| **B** 内层跑满 | `code/L03/my_day3.py` 第 25–26 行 `for i in range(1,4): for j in range(1,4)` | 恒为 n | **n²** | **O(n²)** |
| **C** 三角形 | `code/L03/my_day3.py` 第 31–32 行 `for j in range(1,i+1)`（九九乘法表） | 1,2,3,…,9 | **n²/2** | **也是 O(n²)** |

**n 翻倍时**：O(n) → 时间 ×2；O(n²) → 时间 ×4。

**O() 只看最高阶、丢掉常数**——5.89、1/2 都不写，写 `O(n)` / `O(n²)`。

## 3. 尺子：把"次数"换成"秒"（2026-09-19 本机实测）

| 操作 | 速率 | 测法 |
|---|---|---|
| python 启动（不含计算） | **0.095 s** | `Measure-Command { python -c "pass" }` |
| 取一个字符 + 比一次（最便宜的操作） | **≈ 2×10⁷ 次/秒** | `p1980`：5,888,896 次 ÷ 净 0.25 s |
| "比一对同学"（3 次 abs + 6 次减法 + 两个三数求和 + 总分比较） | **≈ 2.5×10⁶ 圈/秒** | `p5728` N=1000：499,500 圈 ÷ 净 0.19–0.22 s |

**教训（本课教员侧自纠）**：教员最初用"2×10⁷ 次/秒"去算 `p5728`，得 0.025 s，实测 0.19–0.22 s，**差 8 倍**。
→ **尺子不是固定的"次/秒"，它绑在"哪一种操作"上。** 估算前先问：**我这一圈里干几件事？**
（O() 里常数会被丢掉；可一旦真要卡时限，常数就咬人。）

**估算三步**：① 数圈数 → ② ÷ 这一圈的速率 → ③ 跟时限比（时限**以题目页为准**，别凭记忆）。

## 4. 三道题复盘（同一台机器、同一把尺子）

| 题 | 范围 | 朴素写法的代价 | 结果 |
|---|---|---|---|
| **P5728** 旗鼓相当的对手 | N ≤ 1000 | 499,500 对 ≈ **0.2 s** | 双层**能过**，AC |
| **P1102** A-B 数对 | N ≤ 2×10⁵ | ≈ 2×10¹⁰ 对 ÷ 2.5×10⁶ ≈ **8000 s ≈ 2.2 小时** | 必 TLE；改"**字典点名查**"（键 `i+C` 直接查）→ **0.13–0.17 s** |
| **P1554** 梦中的统计 | N ≤ 2×10⁹，**但 N−M ≤ 5×10⁵** | 5×10⁵ 个数 × ≤10 位 ≈ 5×10⁶ 次 ≈ **0.35–0.43 s** | 能过 |

**P1102 的账**：同一题，同一台机器，**"两两比" 2.2 小时 → "点名查" 0.15 秒，差约 5 万倍**。
答案可达 **10¹⁰**（> 2³¹），C++ 必须 `long long`；Python 整数无上限，天然免疫。

**P1554 的坑在"读范围"**：N 最大 2×10⁹ 看着吓人，但真正要处理的是**区间长度 N−M**（≤ 5×10⁵）。
→ **"N 很大"不等于"要处理 N 个"**。

## 5. 本次踩到的四处（第 N 次同类，收尾时并入易错台账）

| # | 错法 | 病灶 |
|---|---|---|
| ① | `p5728` 内层起点写 `s = 1`，ch=1 时变成**自己跟自己比** | **起点/口径**（"从谁开始"没随外层走） |
| ② | `p5728` 总分写成 `x[s][0] + x[s][0] + x[s][0]`（同一科加三遍） | 手滑 + 没先看一遍再交 |
| ③ | `p1102` 换了字典，却把**双层原样搬到键上**（k 个不同值两两比）→ 还是 O(k²) | **换容器 ≠ 换形状** |
| ④ | `p1554` 读时硬取 `treq["8"]` → 区间里没有 8 → `KeyError` → **RE** | **写进去兜了底（`.get`），读出来没兜** |

**判据（本课净增）**：

1. **先算再写**：写之前先估圈数、换成秒、跟时限比；别写完才撞墙。
2. **换形状才算优化**：把"两两比 O(n²)"换成"点名查 O(1)"，而不是给 O(n²) 套个字典。
3. **读范围要读全**：看清题目给的是"总数上限"还是"区间长度上限"。
4. **缺省值要有**：字典读键、区间取位这类地方，先问"这个键/这个数码一定存在吗？"
