## 一、知识地图（六个维度）

### 0. 底层逻辑：一切皆对象
数字、字符串、列表、函数、类——**都是对象**；变量只是**贴在对象上的名字**。
→ 由此推出一条习惯：拿不准"这东西是什么、能做什么"时，`type(x)` 先问一句（✅ `type()`）。

### 1. 数据长什么样（容器四件套）
| 容器 | 记忆法 | 关键写法 / 坑 |
|---|---|---|
| `list []` | 排队名单（有序可改） | 下标 `lst[0]`、负下标 `lst[-1]`、`append(x)` 添加、`len()`、`x in lst` |
| `tuple ()` | 封条盒（有序**不可改**） | `tup[-1]`；**单元素必须写 `(1,)`** |
| `set {}` | 磁贴盒（**无序、唯一**） | 去重靠它；空集合写 `set()`，**`{}` 是空字典** |
| `dict {}` | 点名册（键 → 值） | `d[键]` 读写、`d.get(键, 默认)` 安全取、`for k, v in d.items()` |

- **计数套路（最常用）**：`freq[ch] = freq.get(ch, 0) + 1`
- 一条记录 = 一个字典；多条记录 = **列表里装字典**（L13 台账就是这么存的）
- ⏳ `d.keys()` / `d.values()`（触发器：要遍历未知键 / 求最大频次时）
- ⏳ 切片 `lst[1:3]`、`set` 的交并运算

### 2. 数据怎么流动（控制流）
- **运算**：`+ - * / // %`、比较 `== != < > <= >=`、逻辑 `and or not`（`==` 判断相等，`=` 才是赋值）
- **分支**：`if / elif / else`（前面的门关了我才被问）
- **循环**：`for x in 容器`、`for i in range(起, 止, 步)`（**前闭后开**，想含 n 写 n+1）、`while 条件`
- **出入口**：`break` 立刻退整圈、`continue` 跳过本轮
- **累加器**：先 `total = 0`，再 `total += x`（或 `sum(nums)`）
- 坑：`while` 必须在循环体里推进条件变量，否则**死循环**；`range(3, 12, 3)` 会**吃掉** 12

### 3. 怎么复用（函数 / 类 / 模块）
- **函数**：`def 名字(参数):` → `return 结果`；**只造不跑**，写 `名字(...)` 才执行
  - `print` / `append` **只做事不交货**（调用处拿到 `None`）；`return` 才是交货
  - **返回多个值** → 打包成元组；调用处 `a, b = f()` 拆包接住
  - **作用域**：函数能看见的只有 ①参数 ②自己的局部 ③外面的全局；函数里给参数赋值只改副本，**外面不变** → 想影响外面只能 `return`
- **类**：`class X:` → `def __init__(self, ...)` 初始化属性 → `self.属性` 存数据 → 方法用 `self` 读自己的数据 → `x = X()` 实例化（✅ L11 打卡程序类版）
- **模块 / 标准库**：`import json / os / datetime`；`datetime.date.today()`；`if __name__ == "__main__":` 入口守卫（✅ L12/L13）
- ⏳ `pip install 第三方库`（触发器：agent S1 要调 API 时）

### 4. 数据怎么存下来（内存 vs 硬盘）—— 数据有两个家
- **内存**：一关就没（变量、列表、字典）
- **硬盘**：`with open(路径, "r" / "w" / "a", encoding="utf-8") as f:` —— 模式要选对，**中文必须写 encoding**
- **结构化存档**：`json.dump(数据, f, ensure_ascii=False, indent=2)` / `json.load(f)`；`json` 只认 `dict/list/str/int/float/bool/None`
- **路径跟脚本走**：`os.path.join(os.path.dirname(__file__), "记账日志.json")`（换目录/换机器都不炸）
- **读第一行 vs 读全部**、**追加 vs 覆盖**（`"a"` vs `"w"`）——写之前先问：我是要**加一笔**还是**重写整份**
- 触发器 ⏳：`sys.stdin`（未知行数读到 EOF）

### 5. 出错怎么办
- `try / except` **只抓具体异常**：`except ValueError:`、`except FileNotFoundError:`
- **禁止裸 `except:`**（会把真 bug 一起吞掉）；能预判的输入错误，就让它可重试而不是崩

### 6. 工程与算法（把代码变成"能用的东西"）
- **刷题四步法**：读懂题 → 想清楚 → 写 → 测；**样例 = 最高法庭**（先核官方样例再谈格式）
- **交作业纪律**：AC ≠ 落库；**改文件 ≠ 进历史**（`git add` 进暂存区 → `git commit` 按快门 → `push`）
- **Git**：`add / commit / push / fetch`、`--force-with-lease`（比 `--force` 安全一档）、`.gitignore` 管"以后生成的"、已跟踪的用 `git rm --cached` 取消跟踪（**不改写历史**）
- **复杂度**：工作量 = 每一层圈数相乘再相加；三种形状 A(内层跟外层走 → ≈5.89n → **O(n)**)、B(内层跑满 → **n² → O(n²)**)、C(三角 → n²/2 → **也是 O(n²)**)
- **尺子（本机实测）**：python 启动 ≈0.095s｜取字符+比较 ≈2×10⁷ 次/秒｜"比一对同学" ≈2.5×10⁶ 圈/秒 → **估算前先问"这一圈干几件事"**
- **文档**：一份文件服务三种读者（门面/手册/纪律）必然打架 → **按读者拆**；改结构要同步指针，但**指哪儿改哪儿**

## 二、判据与踩坑（我的）

**五句老判据**
1. 同一状态出现在几处，就几处一起改
2. 改造前后逐条对齐行为
3. AC ≠ 落库
4. **改文件 ≠ 进历史**
5. 改结构要同步指针，但**指哪儿改哪儿**

**L16 新增四条**
6. **先算再写**：估圈数 → ÷ 这一圈的速率 → 跟时限比；别写完才撞墙
7. **换形状才算优化**：两两比 O(n²) → 点名查 O(1)；给 O(n²) 套个字典不算
8. **读范围要读全**：`N` 很大 ≠ 要处理 `N` 个（看的是区间长度）
9. **缺省值要有**：字典读键、区间取位之前先问"这个键/这个数码一定存在吗？"

**我的高频错（截至 2026-09-20，教员台账）**
- 口径/初始状态 **8**（最近一次：`p5728` 内层起点写死 `s=1` → 自己跟自己比）
- 状态同步 3｜谁依赖谁·值从哪来 3｜重写丢约束 3｜产物未落库 3｜引用 vs 调用 2｜暂存区概念漏 1｜提交信息不具体 2
- L16 新增：**换汤不换药 1**（换字典但双层搬到键上）｜**读取缺省值漏 1**（`treq["8"]` → KeyError → RE）｜**算式没算完 1**（写出除法就当结论）
- 统一规律：**"改了东西" ≠ "它进了该去的地方"**（落库 / 暂存区 / 约定位置，同族）
- 新纪律（09-20 立）：问到"**多少个 / 多久 / 几倍**"时，答案里**必须出现一个数**；没有数 = 没答完
