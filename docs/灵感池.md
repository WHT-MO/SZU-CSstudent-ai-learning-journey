# 💡 灵感池（单文件模板）

> 用法：一条灵感一个块，**每块 ≤5 行**，只写能触发行动的要点。
> 生命周期：待孵化 →（决定开工）→ 把"核心需求"抄进 8 问第 1 条并进入项目模式 → 进行中 → 已完成 / 已放弃。
> 纪律：状态列必须更新，否则池子腐烂；不孵化超过 3 个月的就归档或删。
> **收池规则（2026-09-20 学员定）**：**课程里的项目不进灵感池** —— 池子只收"**课程之外、你自己冒出来的想法**"。课程项目由课程日历 + 各课项目文档承接。
> **判据一句话**：这是**课程安排的**，还是**我自己想做的**？

## 模板

```
### 灵感名称：（一句话概括）
- 源头场景：（什么时候、因为什么痛点想到）
- 目标用户：（我自己 / 室友 / 全班）
- 核心需求：（最核心的一件事，只写 1 条）
- 初步思路：（中文流程，不写代码）
- 技术初判：（AI 做哪几步最爽 / 哪一步可能卡住）
- 状态：（待孵化 / 进行中 / 已完成 / 已放弃）
```
