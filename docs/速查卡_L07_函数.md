# ⚡ 速查卡 L07 · 函数 def（3 分钟复习版 · 卡5）

> **一句话核心**：**`def` 只造工具，写 `名字(...)` 才真的跑**；**`return` 交货（能接住、能再算），`print` 只是喊话（调用处只接到 `None`）**。

## 1. 一句话核心
`def 名字(参数):` 把一段活打包成一个名字；要交结果就 `return`——**递出去、有人接、还能接着算**。函数体里造的变量是"**临时工**"，出了函数就消失。

## 2. 关联概念
`def` · 参数（进料口） · `return` · 调用 `名字(...)` · 返回值 / `None` · 多值返回（**打包成元组**）+ 拆包 · 作用域（临时工） · `print` vs `return` · `.append`（同族） · `*` 展开（已讲）
（前接：L04 输入模板 `map/split`、L05 tuple 打包解包｜后续：L08 参数是副本 → `UnboundLocalError`）

## 3. 概念间关系
```python
def average(a, b, c):        # 造工具：只造不跑；a b c 是进料口（参数）
    total = a + b + c        # 函数体：每次调用，缩进的这几行整段跑一遍
    return total / 3         # 交货：把结果递出去（/ 永远给小数 → 90.0）
r = average(90, 80, 100)     # 写 名字(...) 才真的执行；r 接住 90.0

def f1(a, b):
    print(a + b)             # 只"喊给人听"：屏幕出现数字，但没有交货
x = f1(1, 2)                 # → x 是 None（没写 return 就自动交 None）

def week(days):
    return days // 7, days % 7   # 两个值【打包成元组】一起交出去
w, d = week(10)              # 调用处【拆包】接住 → w = 1，d = 3
```
- **造 和 用 是两件事**：只写 `def`，程序什么都不会发生。
- **`print` / `.append` 是"只做事不交货"一族**——调用处只能拿到 `None`。
- **`return` 交出去的值必须有人用 `=` 接住**，否则等于丢弃。
- **内外同名互不打架**：函数里造的变量，出了函数就没了。

## 5. 常见误区
1. ❌ 只写 `def ...` 不写调用，以为会执行 → **什么也不会发生**。
2. ❌ 只 `print` 不 `return` → 调用处拿到 `None`（`r1 = f1(1,2)` 之后打印得到 `None 3`）。
3. ❌ **算了两个值、只 `return` 一个** → 另一个永远是 `None`（"算了两个只交一个"）。
4. ❌ `print(week(b))` → 打印出 `xiao (1, 3)`：**容器的长相 ≠ 内容**（要拆包，或用 `*` 展开）。
5. ❌ `print(a, " ", week(b))` → 多出一个空格：`print` 用逗号分隔时**自己会插空格**。
6. ❌ 写 `函数() = 值` → `SyntaxError: cannot assign to function call`（`=` 左边必须是"能装东西的变量"）。
7. ❌ 在函数外面用函数里造的变量 → `NameError`（`inner` 是临时工，出了函数就没了）。
8. ❌ 函数里先读后写同一个名字 → `UnboundLocalError: cannot access local variable ...`（L08 真撞过：函数里给参数赋值，那个名字就变局部；详见 L08 讲义 §2）。
9. ❌ 传文字忘了加引号 → `greet(小明)` → `NameError`（不加引号 = Python 去找一个叫"小明"的**变量**）。

<details><summary>答案（想完再点开）</summary>

1. 不会——`def` 只造工具，写 `名字(...)` 才执行。
2. `None`——函数没写 `return` 就自动交 `None`；`print` 打在屏幕上，但没有"交货"。
3. 一个**元组**（打包）；调用处 `a, b = 函数()` **拆包**接住（也可以先接住整个元组再取下标）。
4. `NameError`——函数里造的变量出了函数就消失（"临时工"）。
5. `90.0` 和 `90`——`/` 永远给小数（float），`//` 是整除。
