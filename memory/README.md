# 🧠 教员记忆系统（跨会话协议）

> 用途：让新会话的 AI 教员能接上当前课程，不被上下文压缩或新会话打断记忆。
> 学员说“按协议开始”即可；教员先读简短进度快照，再按需查细节。完整教学规则见 `docs/教学机制与协作约定.md`。

## 一、为什么需要这个目录（记忆原理）

1. 模型的"工作记忆"= 当前会话的上下文，**有长度上限**：聊太长时，早期内容会被压缩或截断，细节会丢。
2. 新会话不应假设已经读到上次的完整教学上下文；即使应用能查历史任务，也要先核对当前停点。
3. 本仓库的**磁盘文件作为课程进度的权威记录**；旧任务和纪要可用来查证细节，不能把它们的旧结论直接当作现状。
4. 仓库里 `docs/`（讲义、速查卡）、`code/`（代码作业）、`README.md`（课程日历）本来就承担了大部分记忆；缺的是**对话层记录 + 每次开场主动读取的协议**。本目录补上这一环。

一句话：**每次会话结束把脑子里的东西写进文件；每次会话开始先把文件读回来。** 写入与读取都发生在文件里，与单个会话的生死无关。

## 二、文件分工

```
memory/
├── README.md            ← 本文件：记忆使用说明（规则变化时读）
├── 01_学员档案.md       ← 不怎么变的画像：基础/环境/作息/目标/风格
├── 02_当前状态.md       ← 唯一权威"进度快照"：学到哪/易错点/待办/下一步
├── 03_会话纪要/         ← 每次一页要点纪要（YYYY-MM-DD_主题.md），回溯细节用
│   └── 模板.md
└── 05_历史明细.md        ← 成果细节/学员画像/已学清单/纪律台账（**按需读，不进开场必读**）
```

> 仓库里保留：本协议、`02_当前状态.md`、根 `README.md` 与 `docs/`、`code/`、`tools/`。
> ⚠️ `00_开场词.txt` 已于同日删除 —— 开场口令改用 **"按协议开始"**（见 §五），协议本身就在本文件 §三。

- 教学内容本体仍在 `docs/`、`code/`、`README.md`，这里只存"对话发生了什么 + 当前停在哪"。
- **`02_当前状态.md` 只放当前有效的进度、理解证据、下一步和短待办**（目标一屏、约 ≤4 KB）；历史细节、画像、已学清单和纪律台账放在纪要或 `05_历史明细.md`，按需读取。
- 想保留**逐字稿**时：由学员在界面上复制/导出原文，存到 `03_会话纪要/_raw/`。教员不会（也无法）自造逐字稿，只写纪要。

## 三、教员跨会话协议

### 开场（学员说“按协议开始”）
1. 先读 `02_当前状态.md`，只查与本次任务相关的教学规则；学员档案、纪要、根 README 和历史明细按需读相关段落，避免开场批量读文件。
2. 用一句话复述上次停点和下一步；若学员纠正，以新证据校准快照。
3. 布置练习前核对所需前置；学员说不懂术语、流程或任务要求时，先解释并确认理解，不能套用“先卡 20 分钟”。

### 课中
- 产物照旧落库（`code/` 当日示例与作业、`docs/` 讲义与速查卡）；
- 重要的提问、卡壳点、错因，随手记进当日纪要草稿。

### 收尾（学员说“下课 / 存档 / 收尾”，约 3–5 分钟）
1. 更新 `02_当前状态.md`：进度、易错点、待办、下一步（旧状态直接覆盖，历史在 git 里）；
2. 在 `03_会话纪要/` 新建当日纪要（按 `模板.md` 结构：主题/新知识点/学员表现/作业与 OJ/遗留问题/下次建议）；
3. 若教学日历有行状态变化，同步改 `README.md` 的状态列；
4. 向学员汇报一句："记忆已更新：02_当前状态 + 纪要 xxx。"

课中重要状态可随时写盘，避免信息丢失；**git 提交和推送只在学员确认收尾时一次性做**，除非学员明确说“现在提交”。自然停顿不等于确认收尾。

### 应急：上下文快满时
会话太长时直接说 **"先存档"**，教员只做收尾第 1、2 步（很快），然后学员**开新会话**继续，开场词照旧。存档不需要等下课，任何时刻都能做。

### 协作模式（精简，**权威全文**见 `docs/教学机制与协作约定.md`「机制 4」）
- 默认“教学模式”：学员写作业和项目代码；任务已清楚时独立尝试，同一实现点卡约 20 分钟记一句卡点。不懂前置概念、流程、报错或题意可立即提问。
- "代写模式"：学员明确说"直接做 / 帮我装（非学习任务）"时教员直接执行（系统管理、工具安装等）。
- **收紧（2026-09-12）**：默认**只指"哪行错 + 为什么 + 反问"**——不给骨架/填空/零件清单（学员两次提出"骨架+填空≈直接给答案"）。
- **节奏（2026-09-11）**：**过程监督 → 结果诊断**——学员先写，教员一次性列缺陷并标注"第几次同类错"；底线=验收须有样例与输入输出证据、测例要有检验力。

## 四、纪律
- 每次完成一格课后更新状态与简短纪要；跨会话需要延续的重要信息可在课中写盘。
- `02_当前状态.md` 只留最新状态，避免多个"版本"打架。
- 纪要写"对人有用的事实"，不写流水账：错点、疑问、决策比讲过的每句话值钱。
- 记忆加载由教员主动完成；学员只需说“按协议开始”，结束时说“下课 / 存档 / 收尾”。
- **纪律入库门槛与去重（token 卫生）**：纪律先当口头行为执行，**真踩坑 ≥1 次才写入文档**；每条纪律只保留**一处权威全文**（`docs/教学机制与协作约定.md` 机制 1–4；2026-09-18 之前那处是根 README），其余一律"一行摘要 + 指针"，不重复正文；每周收尾做一次纪律体检（合并/删除过期项）。

## 五、会话口令与"独立任务"隔离（2026-09-13 定）

- 开场：**“按协议开始”**（先读 `02_当前状态.md`，其他文件按需读取；“按协议加载”视为同义口令）；
- 收尾：**"按协议收尾"**（写状态+纪要+同步日历）；变体 **"只存档"**（只写盘）、**"先存档"**（应急，只做收尾 1、2 步）。
- 独立任务（做 PPT / 查资料 / 装工具等）：**开新会话，开场说"独立任务，不加载教学记忆：X"**；产物放自己的目录，不写进 `python-course`。
- 完整细则（含四种情形对照表、token 卫生、为什么"换会话才真隔离"）见 **`05_历史明细.md` 第六节**。
