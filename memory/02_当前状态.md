## L15 三条核心结论（下次复习可用）
- **两个区**：改文件 ≠ 进历史；`git add` 摆进**暂存区**（红→绿），`git commit` 才**按快门**；
- **`git status` 的红不是错误**（红 = 没暂存 / 没被跟踪）；`fatal:` 打头才是报错，且多半是**不在仓库文件夹里**（`cd` 只对当前窗口有效）；
- **`.gitignore` + `git rm --cached`**：忽略规则管"**以后**"；已进历史的要"取消跟踪"（**磁盘文件不动**），且**不改写历史**（改历史要 rebase/filter-repo，不值当）。
