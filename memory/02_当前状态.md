## L13 三条核心结论（下次复习可用）
- **数据的两个家**：内存（程序一关就没）vs 文档（硬盘）。流程 = `input` → 内存列表 → `save()` 整份写回；开机 `load()` 读一次；看全部/汇总**只读内存**。
- **形状**：一条记录 = 一个字典（按键取值，加字段不动别处）；很多条 = **列表装字典**；汇总 = 遍历 + `dict` 累加，`items()` 一次拿键和值。
- **json**：只认 dict/list/str/int/float/bool/None；`date` 要 `str()`；`ensure_ascii=False`（中文可读）+ `indent=2`（记事本可读）。
