## 近期三条核心结论（复习用）
- **复杂度**：工作量 = 每一层圈数相乘再相加；**"双层"不是罪名，n 才是**（n=1000 → 50 万对 ≈0.2s；n=2×10⁵ → 200 亿对 ≈2.2h）。优化 = **换形状**（两两比 O(n²) → 点名查 O(1)），不是给 O(n²) 套个字典。
- **尺子（本机实测）**：python 启动 ≈0.095s；取字符+比较 ≈2×10⁷ 次/秒；"比一对同学"（三科 abs + 两个求和）≈2.5×10⁶ 圈/秒 → **尺子绑在"哪种操作"上，"一圈干几件事"要算进去**。
- **读范围要读全**：P1554 里 N ≤ 2×10⁹ 但 **N−M ≤ 5×10⁵** —— **N 大 ≠ 要处理 N 个**。
