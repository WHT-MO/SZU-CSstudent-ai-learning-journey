- ⑰ **单条输出过载（09-21 放学格 2）**：讲完数据库后，一条消息里同时甩出"文件/数据库对照表 + `commit`/原子性/主键编号 + 三个 SQL 动词 + 下一格预告"→ 学员回"**你在说啥，我看不懂**"，被迫整段重讲。→ **纪律：一条消息只推一个概念；新概念不上术语；讲完一个小结论就停下来问一句**。与 09-17"一轮一件事"、09-19"先给地图再问问题"**同源，是同一个毛病的第三次复发**。
- ⑱ **PowerShell 引号转义想当然（09-21 放学格 2）**：在 `pwsh -Command` 里用 `\"` 转义双引号 → 解析器报 `Missing argument in parameter list`。→ **含引号/多行的脚本一律先写成 `.py` 文件再跑**。
- ⑯ **把"门牌"当"房子"（09-21）**：断言 `where.exe python` 是"照妖镜"、足以定位程序本体；实际它给的 `...\WindowsApps\python.exe` 是 **Windows 应用执行别名 = 0 字节门牌**，真身在 `C:\Program Files\WindowsApps\PythonSoftwareFoundation.Python.3.12_3.12.2800.0_x64__qbz5n2kfra8p0`。→ **新硬纪律：环境结论三步 = `where`（有几个）→ `Get-Item`（多大/是不是门牌）→ `Test-Path`（真身在哪）**，少一步就是"想出来的"。
- ⑮ **拿平均数当本次事实（09-21）**：把"14 会话平均 194K/次、记忆占 3–5%"当成本次开场的预期，被学员追问（开场 cacheRead ≈ 51.6 万、真实上下文 32.2K/记忆占 ≈20%）。→ **纪律：引用任何用量数字先报口径与分母，要"本次"的数就现场读 `~/.dsh/storages/session_projcache/sessions/<id>.json`**。
- ⑭ **把陈旧注册当事实**（09-20）：用 `py -0p` 的输出断言"机器上有两个 Python（3.12 + `D:\app\Python\3.11`）"，**没做 `Test-Path` 就下结论**；实际 `D:\app\Python\` 不存在，那是 py 启动器注册表里的**陈旧登记**，学员当场纠正。（**与 ⑯ 同族：登记 ≠ 存在；门牌 ≠ 房子。**）
