## 2. 新知识点（给未来复习的浓缩版）
- **类 = 说明书，对象 = 按说明书造出来的实物**；`class Kaoqin:` 只定义、不执行；`Kaoqin()` 才造对象（这一步跑 `__init__`）。
- **`__init__`**：造对象时自动跑的那一趟，用来给新对象装上初始数据；第一个参数 `self` 由 Python 自动塞（调用时不传）。
- **`self` = 这个对象自己**；`self.last` = "它身上的 last 那一栏"（`self` 与 `self.last` 不是一回事）。
- **数据住对象，方法住类**（实测：`Dog.__dict__` 里只有方法，`Dog.name` 取不到）。
- **不带 `self.` 的查找顺序**：局部 → 外层 → 全局；全都没有才 `NameError`；**全局恰好有同名 → 静默用错值**（"不报错的错"）。
- **类属性 vs 实例属性**：`class Kaoqin: bag = []` 是**共享**的（一个对象 append，另一个也有）；状态必须用 `self.xxx`。
- 约定：类名大驼峰 `Kaoqin`，方法/变量小写+下划线；`f"..."` 小写 f。
- 速查卡：`docs\速查卡_L11_类与对象.md`（卡7，七件套 + 5 自检题）。
