## 2. 学员本轮两处修改（自己发现 + 自己改）
1. **新用户误判**：`last == today - 1` 在 `last = 0`（从没打过卡）时**也成立**（`0 == 1-1`），导致新用户一进来"看记录"就报"已连续打卡 1 天"。
   - 修法：条件补 **`and last != 0`** —— 用 **`last = 0` 当哨兵值**表示"从未打卡"，把它排除在"昨天打过"之外。
2. **今天已打卡的口径**：把"看记录"在 `d == 0 and last == today` 时补成 `d = 1`，让"已打卡但未续跑"的情形也能显示 1 天。
