## 2. 新知识点（浓缩）
- 字符串方法：`lower/upper/strip/split/count/replace/isdigit/join`；**字符串不可变**——方法返回新值，`s = s.upper()` 要接住
- split 与 join 是相反兄弟；`len` 是函数、方法是挂载的
- tuple：有序不可改；打包/解包（`a,b = 1,2` 早就在用）；`(1,)` 单元素要逗号；能当字典钥匙
- set：无序唯一去重；`len(set)/sorted(set)`；集合运算 `| & -`（点名差集）；`{}` 是空 dict、空 set 写 `set()`
- 多行输入三模式（教未练，L06 起会用）：for+input（先给 n）/ 列表收集 / `sys.stdin` 读到 EOF
