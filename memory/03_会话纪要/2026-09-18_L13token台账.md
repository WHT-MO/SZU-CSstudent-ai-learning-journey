## 2. 新知识点（给未来复习的浓缩版）
- **数据的两个家**：内存（`self.records`，程序一关就没）vs 文档（硬盘）。流程 = `input` → 组装字典 → `append` 进内存列表 → `save()` **整份写回**；开机 `__init__ → load()` 读一次；看全部/汇总**只读内存**。
- **形状**：一条记录 = **一个字典**（按键取值，加字段不用改别处）；很多条 = **列表装字典**；汇总 = 遍历记录、`dict` 边累加边分组，`items()` 一次拿键和值。
- **json**：只认 dict/list/str/int/float/bool/None；`date` 对象要 `str()` 化；`ensure_ascii=False`（中文可读）、`indent=2`（记事本可读）；`json.dump(数据, 文件对象)` / `json.load(文件对象)`；一次 dump 只处理**一个**值——多条数据要装进一个容器再 dump。
- **datetime**：`from datetime import date` → `date.today()`；`str(date.today())` = `2026-09-18`（这种写法**字符串比大小 = 日期先后**，`2026-9-7` 则会乱）。
- **import 机制**：`import 模块名`（**不带路径、不带 `.py`**）；**import 会把目标文件从头执行一遍** → 顶层有菜单循环的文件，谁 import 谁弹菜单；这就是 `if __name__ == "__main__":` 存在的全部理由。`__name__`：直接运行 = `__main__`，被 import = 模块名（学员用 `m1.py`/`t2.py` 实测过）。
- **`__pycache__/*.pyc`**：import 的副产品（字节码缓存），`cpython-312` 是版本戳；删了会自动重建；`.PYC` 不在 `PATHEXT` 里不能当命令敲，但 `python xxx.pyc` 能跑。
- 顺带：`enumerate(列表, 1)`（序号 + 元素，`i, r` 是 L05 的 tuple 解包）；`ask_int` 里用 `try/except ValueError` 挡非数字输入（L10 的"只抓具体异常"）。

## 3. 学员表现 & 易错点
- **设计自己做主**：字段（日期/模型/输入/输出）、存储用"整份重写"（理由：预计只有几十条）、汇总维度按日期 —— 教员只质疑、不改结构。
- **质疑教员（且质疑得对）**：指出"这个课的作用是让我学语法，不是做出一个日常使用的项目，能用就可以了" → 教员当场收回"口径/价目/缓存分列/加码验收"的过度设计（教员侧账 ⑪）。
- **会读代码、追问机制**：`ask_int` 用得到吗 / `add()` 里为什么不用 `self.` / `enumerate` 是什么 / `if __name__ == "__main__"` 是什么 / `import` 怎么写 / `.pyc` 是什么 —— 六问全在关节上。
- **本课新增易错**：
  - 「状态同步」**第 3 次**：存档形状换成字典后，`read()` 仍写 `self.back[2]`、`check()` 仍写 `self.back[0..3]`（按旧平铺列表读）→ 必 `KeyError`；
  - 「谁依赖谁 / 值从哪来」**第 3 次**：数据流答"汇总时读文档"，实际读**内存**；
  - 「重写丢约束 / 决定与实现不一致」**第 3 次**：定了"整份重写"，代码写成 4 次 `"a"` 追加（一条记录的 4 个值各 dump 一次）；
  - 「产物未落库」**第 3 次**：说"我跑完了"，但 `code/L13/` 里没有任何存档文件 → 重跑一次才落盘；
  - 「引用 vs 调用」**第 2 次**：`print(d)`（第 1 次是 09-17 的 `print(hanshu)`）；
  - 报错原文两条：`AttributeError: 'str' object has no attribute 'json'`（把 `json.dump` 当成"值的方法"，且把变量名写进了引号里）、`SyntaxError: invalid syntax`（`import` 后面直接写文件路径）。
- **09-17 那笔"报错类型辨别"**：用"函数里有没有赋值"讲清 `NameError` vs `UnboundLocalError`（后者是前者的子类），`int("abc")` → `ValueError` 答对。
