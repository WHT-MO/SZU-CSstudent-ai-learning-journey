## 2. 新知识点（给未来复习的浓缩版）
- **仓库 / 工作区 / 暂存区 / 提交**：改文件 ≠ 进历史；`git add` 把改动摆进**暂存区**（红 → 绿），`git commit` 才**按快门**（历史多一格）。
- **`git status` 的红不是错误**：红 = "没暂存 / 没被跟踪"；只有 **`fatal:` 打头**才是报错，而它多半意味着"**你不在仓库文件夹里**"——`cd` **只对当前窗口有效**。
- **`.gitignore`**：一行一条规则；`#` 注释；`*` 通配；结尾 `/` = 目录；`[cod]` 是字符组（`*.py[cod]` = pyc/pyo/pyd）。语义是"**以后生成就拦**"，**不拦**已存在或已进历史的文件。
- **`git rm -r --cached <路径>`**：取消跟踪，但**磁盘上的文件不动**；**不改写历史**（历史里那格仍有它）；要真从历史抹掉得 rebase / filter-repo —— 不值当。
- **远程**：`git remote add origin <url>`；**`git fetch` = 只取下来看不合并**，`git pull` = fetch + 合并；`git push -u origin main` 的 `-u` = **绑定上游**（以后裸 `git push` 即可）。
- **`--force-with-lease`**：覆盖远程，但要求"远程仍是我刚 fetch 到的那个头"，否则**拒绝** → 比裸 `--force` 安全一档；输出里的 **`+ e35caac...90e526f main -> main (forced update)`** 就是强制覆盖的记号（`+` 与 `forced update` 普通推送没有）。
- **换行符 warning**：`core.autocrlf=true`（系统级 gitconfig 默认）→ 工作区 CRLF、仓库 LF；`warning: LF will be replaced by CRLF` **无害**；唯一会咬人的是同一文件**混用**两种换行（diff 会显示"整文件都改了"）。
- **显示中文文件名**：`git config --local core.quotepath false`（否则非 ASCII 名字显示成 `\350\256\260` 八进制）。
- **短 / 长选项**：`-uall` ↔ `--untracked-files=all`（一个减号 = 短、两个 = 长，**不能拼**）；卡住就敲 `git status -h`。
- **本机环境**：`github.com` 被 hosts 指到 `127.0.0.1`（本地加速器）→ 裸 git 连不上；仓库级设 `http.sslBackend=openssl` + `http.sslVerify=false` 后推送成功（正路是把代理根证书装给 git）。
