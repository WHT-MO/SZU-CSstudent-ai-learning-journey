## 2. 新知识点（给未来复习的浓缩版）
- **`sys.stdin`（本课解锁）**：程序启动时有三根管子 —— `stdin`(0) 输入 / `stdout`(1) 输出 / `stderr`(2) 错误。**`input()` = 从 stdin 读一行 + 剥掉行尾换行**；`sys.stdin` 是**文件式的流**，可以 `for line in sys.stdin:` 逐行迭代 → **行数未知时用它**（读到结束自动停，不抛 `EOFError`）。
  - 两处必记差别：迭代出来的行**保留** `\n`（`int(line)` 通常仍可，但 `int("\n")` 会 ValueError）；**EOF 在 Windows 控制台 = Ctrl+Z 再回车**（Linux/macOS = Ctrl+D），**空行不是 EOF**。
- **`pip`（本课解锁）**：`python -m pip install requests` → 装上 **requests 2.34.2**；用 `python -m pip show 包名` 核对。铁律：**装库永远写 `python -m pip`**（裸 `pip` 可能属于另一个解释器）。
- **排查姿势**：`ModuleNotFoundError` ≠ 代码错，是"**当前这个解释器里没有这个库**"；先确认"跑我代码的解释器是哪个"（`sys.executable`）。
- **喂输入的四种方式**：① 输入写文件 + `Get-Content x.txt | python y.py`（**推荐，可重复**）② VS Code 终端里手敲 ③ 交互式手敲后 Ctrl+Z ④ 洛谷「自定义测试」。⚠️ PowerShell **不支持 `< 文件`** 重定向（那是 cmd）。
