## 2. 新知识点（给未来复习的浓缩版）
- **三档"别人的代码"**：内建（`print`/`open`，开机就在）｜标准库（`os`/`sys`/`json`/`math`，**要 import**）｜第三方（**要 `pip install`**）。
- **`import` 三写法**：`import os`（带前缀，默认）／`from os import path`／`as` 别名；铁律 **import 之前名字不存在** → `NameError`。
- **PATH**：敲命令 = 系统拿 PATH 里的文件夹**挨个找**；`where.exe` 当侦探；**PATH 只负责"去哪找"，不保证"那里有"**（`D:\app\Java\bin` 在清单里，可里面没有 `java.exe`）。
- **路径**：**相对路径跟 cwd（人在哪），不跟脚本（文件在哪）**；`__file__` = 本文件路径（3.9+ 绝对路径）；`os.path.dirname(__file__)` = 它所在文件夹；`os.path.join` 拼路径，别手写 `\`。
- **读 traceback 三动作**：看最后一行 → 看谁调用谁 → **扫有没有自己的文件名**（没有 = "跑它的方式"的锅；实例：VS Code F5 走 debugpy，报 `ConnectionRefusedError [WinError 10061]`）。
- **三种错别混**：`NameError`（没这个人）／`UnboundLocalError`（有工位、还没上班）／`ValueError`（人对了、给的数不对）。
- 成品形态：`code\L12\kaoqin.py` 在 `__init__` 里算一次 `self.path`，**三处 `open()` 共用**（对应 L11 版第 67/83/88 行）。
- 速查卡：`docs\速查卡_L12_模块与标准库.md`（卡8）；讲义 `docs\L12_模块与标准库.md`。
