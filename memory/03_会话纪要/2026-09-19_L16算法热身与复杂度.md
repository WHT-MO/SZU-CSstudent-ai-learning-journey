## 2. 新知识点（给未来复习的浓缩版）
- **形状三兄弟**（全用学员自己的代码当教材）：
  - A `code/L09/p1980.py:21-22` 内层跟着外层走（a 几位跑几圈，平均 5.89）→ **≈5.89n → O(n)**；
  - B `code/L03/my_day3.py:25-26` 内层每圈跑满 → **n² → O(n²)**；
  - C `code/L03/my_day3.py:31-32` 九九乘法表 `range(1,i+1)` 三角 → **n²/2 → 也是 O(n²)**。
- **尺子（本机实测）**：`python -c "pass"` = 0.095s；取字符+比较 ≈ **2×10⁷ 次/秒**；"比一对同学"（3 次 abs + 6 次减法 + 两个三数求和 + 总分比较）≈ **2.5×10⁶ 圈/秒**。
- **估算三步**：① 数圈数 → ② ÷ 这一圈的速率 → ③ 跟时限比（时限以题目页为准）。
- **O() 记号**：只看最高阶、丢常数；n 翻倍 → O(n) ×2、O(n²) ×4。
- **换形状才算优化**：P1102 从"两两比"（≈2.2 小时）改成"字典点名查"（**0.13–0.17s**），差约 **5 万倍**；答案可达 10¹⁰（> 2³¹，C++ 要 `long long`，Python 无上限）。
- **读范围**：P1554 的 N ≤ 2×10⁹ 但 **N−M ≤ 5×10⁵** → 要处理的是区间长度，**N 大 ≠ 要处理 N 个**。
