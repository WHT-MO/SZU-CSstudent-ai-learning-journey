## 2. 新知识点（浓缩）
- 列表：一排**编号从 0 开始**的储物柜；`[0]` 第一个、`[-1]` 倒数、`len()` 长度、`append()` 追加、切片 `[1:3]` 前闭后开
- 遍历：只要内容用 `for x in 列表`；需要序号才 `range(len(列表))`
- 咒语拆解：`input()` 端整行 → `.split()` 按空格切段（**切完仍是文字**）→ `int()` 逐段变数字 → `a,b,c = map(int, input().split())`
- 批量存储：`nums = list(map(int, input().split()))`；内置 `max/min/sum`
- 心智模型：变量=单个盒子；列表=编号储物柜排；for 遍历=从 0 号柜走到最后一号
