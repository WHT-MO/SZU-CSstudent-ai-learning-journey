## 2. 新知识点 / 新工具
- **新解锁**：`.append()`｜`[初值] * n`（固定长度造表）｜list **下标赋值**（读/改共用方括号）。
- **转正**：`.rstrip()`（挂账 3 天结清）、`sum()`（进 §5"累加器三条路"）、`+=` / `-=`。
- **讲透的机制**：`map` = 逐个变换的迭代器（**不负责切分**；喂字符串 → 逐字符，故 `"12"` 变 1 和 2）；`()` = **执行扳机**（空参数也必须写；括号里放参数）；`for k in d` 为什么给键（**字典的身份就是键**，无第二种默认）；`items()` 把每对打包成 `(键, 值)`，`for k, v in ...` 是**拆包**（与 `a, b = (1,2)` 同族）。

## 3. 核心结论（本课最有价值的一条）
> **区间"重合"不需要合并、也不需要判断——它取决于你用什么记法。**
> - 记法甲「**每格一个状态**」（`trees[i] = 1`）：同一格被赋值两次，结果不变 → **重合自动消失**；
> - 记法乙「每段一条记录」：才需要合并/判重。
>
> 学员据此否掉了自己以为要处理的重合问题，并自行得出"**位置是数据，只能改状态不能删元素**"（若删元素，后面全部前移、位置编号失真）。
> 附：学员最初担心"累加器会被重合骗"，**这个直觉对了一半**——数**动作**会被骗（`removed += 1` 写在赋值前），数**状态**不会（赋值前先问"这里原来是不是 0"）。已讲清"记录结果安全 / 累计操作要防重复"，学员表示不实现路 B（跳过）。
