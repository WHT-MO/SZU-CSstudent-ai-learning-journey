# 📋 会话纪要模板

> 每晚会话收尾新建一页，文件名：`YYYY-MM-DD_主题.md`（如 `2026-09-09_L04.md`）。
> 写"对人有用的事实"，不写流水账。以下为必填骨架，可按需增删小节。

# 2026-XX-XX · LXX 主题

## 1. 本课主题
一句话：今晚讲了什么、上到哪停的。

## 2. 新知识点（给未来复习的浓缩版）
- 概念 / 语法 / 模板代码要点（可引用 `docs/LXX_*.md` 和 `code/LXX/` 里的文件）

## 3. 学员表现 & 易错点
- 提问过什么（说明哪里会卡）
- 犯过的错、错因（报错原文可附）
- 费曼检验判定（如做了）：看懂了 / 基本掌握 / 真正掌握
- 表扬点（哪些一次就懂，下次可少花时间）

## 4. 作业 & OJ
- 作业内容、是否提交、review 结论
- OJ 题目、得分（洛谷 AC?）
- 卡住没做出来的题 → 列入待办

## 5. 遗留问题 / 待办
- 下次开课必须先处理的事（按重要性排序）

## 6. 下次开课建议
- 建议从哪接续、预计内容、需要学员提前准备什么
