## 2. 新知识点（给未来复习的浓缩版）
- **文件读写**：`with open(路径, 模式, encoding="utf-8") as f`（用完自动关门）；`f.write()` 写、`f.read()` 整串读回；`\n` 必须自己写（`write` 不自动换行）。
- **模式三兄弟**：`"r"` 读（文件不在就报错）｜`"w"` **清零重写**｜`"a"` 追加。判据：**状态快照用 `"w"`，日志才用 `"a"`**。
- **异常处理**：`try` / `except 具体类型`；只抓预期类型，**不写裸 `except`**（它会连自己的 bug 一起吞掉）；报错**最后一行**就是类型名（`FileNotFoundError` / `ValueError`）。
- **编码**：字 ↔ 字节的**对照字典**；乱码 = 写和读用了**不同的字典**；中文 Windows 默认 GBK，故显式 `encoding="utf-8"`（若文件被 BOM 污染，读用 `"utf-8-sig"`）。
- **路径**：相对路径相对 **cwd**（敲命令时所在目录），不是脚本所在目录。
- **读档模板**：`last, d = map(int, f.read().split())` —— 与 L04 输入模板同一套动作，只换了数据来源。
- 细节全在 `code\L10\kaoqin.py` 文件头（核心决策 / 卡点 / 取舍 / 验收）与 `docs\语法模板卡.md` §5。
