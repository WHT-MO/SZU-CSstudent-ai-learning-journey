## L09 刷题方法课（2026-09-13 晚）
- **四步法复述**：首答第 3、4 步笼统（"过程怎么实现 / 设计步骤"）→ 追问后补答"**第 3 步产出数据结构，第 4 步产出实现步骤**"→ 通过。
- **P1980 计数问题**：v1 攒 600 万元素列表 + 两趟遍历 → 大数据 TLE；v2 一趟 + 计数器（`int(b)==x`）→ 本机 0.39s 仍 TLE；v3 循环外 `x=str(x)` 字符比较 → 0.15s **AC**。实测对照：0.39 / 0.15 / 0.09s（v3 = `''.join(map(str,range(1,z+1))).count(str(x))`）。
- **P1420 最长连号**：v1 用 `a[b-1]` 而 `b` 从 0 起 → **负下标绕到末尾**，把"尾+1==首"当"接着"（洛谷 AC 属运气，构造 `6 / 6 1 8 2 9 5` 实测输出 2、真答案 1）；v2 改用 `break` 跳过首轮 → 第一轮掐死整圈，`n>1` 全输出 1；v3 改 **`continue`** → 六用例全过。
- **两条结论**：① `n` 的范围是提示（能不存就不存），算法对 ≠ 一定过（Python 层动作贵，C 实现的内置函数快一个数量级），评测机比本机慢；② 两个"不报错的错"——负下标 `a[-1]` 合法、`break` vs `continue` 分不清。
- 教员自纠：曾推测"洛谷 Python 有时限放宽"，未核实 → 当场撤回。

## L10 正课 · 文件读写 + 异常处理（2026-09-14 下午，提前于 09-15 日历）

- **当天真撞的坑（全部由学员亲手撞出或修掉）**：
  1. `open(路径,"w")` **会先把文件清零** → 两次 `"w"` 各写一行只剩后写的；追加要用 `"a"`；
  2. **相对路径跟 cwd**、不跟脚本：换目录跑，存档落到那个目录里；
  3. **编码**：gbk 字节按 utf-8 读就是乱码（读写两端都要 `encoding="utf-8"`）；
  4. 清空写成 `f.write("")` → 空文件下次启动 `ValueError: not enough values to unpack`；
  5. **清空只改文件、不改内存** → 退出前外层写档把旧值写回 = **清空无效**；改法 = 内存 `last = d = 0` + 写 `"0 0"`（状态同步类错，与 L08"读操作改状态"互为反面）。

- **已知取舍（学员决定，非缺陷）**：① 新用户不询问"今天是第几天"，默认 `today = 1`（代价：不在第 1 天开始用时连续天数从 1 重算）；② 清空后直接退出菜单；③ 清空后启动显示"上次打卡第0天"（哨兵 0 直接显示）。

## 6.1 开场 / 收尾口令
- 开场：**"按协议加载"** → 读 `README.md → 01_学员档案.md → 02_当前状态.md → 最近 1–3 篇 03_会话纪要/ → 根 README 日历`，先复述进度；

- 变体：**"只存档"**＝只写盘不啰嗦；**"先存档"**＝上下文快满时的应急存档（只做收尾第 1、2 步）。

## 6.2 独立任务隔离（原则：**记忆按仓库分家，会话按任务分家**）
| 情形 | 做法 | 开场怎么说 |
|---|---|---|
| 一次性独立活（做 PPT、查资料、装工具） | **开新会话**，不加载教学记忆、**也不写教学记忆** | "**独立任务，不加载教学记忆：帮我做 X**" |
| 独立活但要留产物 | 产物放它自己的目录（如 `D:\code\dsh\<项目>\`），**不写进 `python-course`** | "**独立任务，不加载教学记忆：帮我做 X。产物存 …**" |
| 长期独立项目 | 给它**自己的目录 + 自己的精简记忆文件**；判断标准：这份记忆对"Python 教学"有用吗？没用就不进教学库 | 同上 |
| 必须在教学会话里插一段（如 PPT 内容是这几课知识点） | 先"**切到独立任务：X**"（教员只做这件事、不更新教学记忆）→ 做完"**回到教学**" | "**切到独立任务：…**" / "**回到教学**" |

**为什么"换会话"才是真隔离**：① 教学记忆不被无关内容污染（`02_当前状态.md` 每场必读，最贵）；② 教员不会带着无关上下文继续教课（输出变长、跑题）；③ 学员 token 不被无关上下文拖累。

## 6.3 Token 卫生（2026-09-13 实测与措施）
- **实测**：开场必读（README + 档案 + 状态 + 最近 3 篇纪要）瘦身前 ≈ 29.5 KB/会话；
- **措施**：① `02_当前状态.md` 只留"当前有效"，细节移入 `05_历史明细.md`（按需读）② `README.md` 的口令/隔离章节压成"口令 + 指针"，完整版移入本文件 ③ 纪要目标 **≤ 2 KB/篇**，过程性内容进 `03_会话纪要/_raw/`；
- **教员侧默认**（比文件瘦身更省）：回复精简（"哪行错 + 为什么 + 反问"）、工具输出只贴关键行、读文件用 `grep`/`offset` 取段、讲过的概念只给指针、已实测过的数字不重复回显。
